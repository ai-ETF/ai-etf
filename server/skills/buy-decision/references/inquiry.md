# 追问链（6步）

## 概述

追问链的目的是帮用户建立理性投资思维，而不是替用户做决定。6步追问循序渐进，从"为什么"到"怎么做"，每一步都让用户自己思考。

## 流程

```
追问1: 投资目标（为什么想买）
  ↓
追问2: 投资期限（打算投多久）
  ↓
标的理解（直接给，不追问）
  ↓
追问3: 风险认知（最坏情况能接受吗）
  ↓
追问4: 自我匹配（结合数据让用户自己判断）
  ↓
追问5: 买入后规则（四条纪律）→ 见 four_rules.md
```

## 通用原则

1. **每次只问一个问题**，不要一次抛多个问题
2. **用户的回答要记录**，用于后续步骤引用和生成执行计划
3. **追问是引导，不是审讯**，语气要温和
4. **如果用户回答已覆盖后续问题，跳过**
5. **如果用户表现出不耐烦，快速收束**

## 追问1：投资目标

**目的**：了解用户为什么想买，判断是跟风还是经过思考

**话术**：
> "第一个问题：你为什么想买{标的}？是觉得便宜了、看到别人赚了、还是有自己的判断？"

**需要记录的信息**：
- 用户的买入动机（抄底/跟风/经过研究/配置需求）
- 对当前市场的看法

**根据回答判断**：
- 如果用户说"看到别人赚了/一直涨" → 有FOMO倾向，通知莱拉
- 如果用户说"估值低想抄底" → 有一定思考，记录逻辑
- 如果用户说"长期配置" → 风格偏稳健

## 追问2：投资期限

**目的**：了解用户打算持多久，判断投资风格

**话术**：
> "你打算这笔钱投多久？是短期想赚一波就走，还是打算长期持有？"

**需要记录的信息**：
- 投资期限（短/中/长期）
- 对资金流动性的需求

**根据回答判断**：
- "几个月" → 短期，需要提醒波动风险
- "1-3年" → 中期，需要关注基本面拐点
- "3年以上/不确定" → 长期，适合定投
- "用闲钱" → 抗风险能力较强

## 标的理解（直接给，不追问）

**目的**：让用户了解标的的基本情况，为后面风险认知打基础

**做法**：直接给出标的的核心信息，不需要用户回答

**话术**：
> "在继续之前，先帮你了解一下这两个标的："
>
> "{标的A}：{一句话描述，如'追踪中证主要消费指数，50只成分股中白酒占比约35%'}"
>
> "{标的B}：{一句话描述，如'追踪中证消费80指数，80只成分股更分散，白酒占比约25%'}"
>
> "简单说，{标的A}偏龙头集中，{标的B}更分散。这个差异后面会结合你的情况分析。"

**内容来源**：小研返回的简要数据报告中的成分股/权重信息，以及RAG中的行业分析框架。

## 追问3：风险认知

**目的**：让用户正视风险，建立底线思维

**话术**：
> "接下来这个问题比较重要：如果买了之后浮亏20%，你会怎么做？是会慌着想卖、加仓摊薄、还是能忍住不动？"

**需要记录的信息**：
- 风险承受能力（强/中/弱）
- 亏损时的预期行为（卖出/加仓/持有/不确定）

**根据回答判断**：
- "会卖" → 风险承受弱，后续要强调仓位控制
- "会加仓" → 需要在四条纪律中强调补仓条件
- "能忍住" → 风险承受强，但需确认是真的理性还是盲目乐观
- "不确定" → 诚实，需要在四条纪律中给出明确指导

## 追问4：自我匹配

**目的**：结合前面收集的信息和简要数据，让用户自己判断是否匹配

**话术**：
> "综合一下前面聊的："
>
> "- 你的目标：{用户回答的投资目标}"
> "- 你的期限：{用户回答的投资期限}"
> "- 你的风险承受：{用户回答的风险认知}"
>
> "然后看数据："
> "- 当前估值：{简要数据中的估值分位}"
> "- 基本面趋势：{简要数据中的基本面趋势}"
> "- 资金流向：{简要数据中的资金流向}"
>
> "结合你自己的情况，你觉得现在买{标的}适合你吗？"

**核心原则**：
- 把信息和判断**并排呈现**给用户
- **问用户的看法**，不给结论
- 用户如果犹豫，可以说"没关系，我们继续往下看详细数据，看完你再判断"

## 追问5：买入后规则（四条纪律）

**目的**：在用户决定买入之前，帮他制定买入后的操作纪律

**详细话术**：见 [four_rules.md](four_rules.md)

## 跳过规则

以下情况可以跳过部分或全部追问：

| 情况 | 处理 |
|------|------|
| 用户回答已覆盖后续问题 | 跳过被覆盖的追问 |
| 用户直接说"别问了，给我看数据" | 跳过追问链，直接进入详细数据报告 |
| 用户回答很简单但愿意配合 | 加快节奏，简化追问 |
| 用户已经是老手（用语专业） | 可以简化前3步，重点问4和5 |
