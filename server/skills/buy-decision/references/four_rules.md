# 四条纪律

## 概述

四条纪律是买入决策Skill的核心约束，**仓位高于一切**。在用户决定买入之前，帮他制定买入后的操作纪律。

核心原则：
1. 买入前：追问链帮用户建立了理性
2. 买入后：面对真实盈亏，情绪回归，容易做出与买入逻辑矛盾的举动
3. 所以必须在买入前就制定好规则，写在纸上，而不是靠情绪记忆

## 进入时机

追问链第5步。用户经过前4步追问后，已经了解了自己的目标、期限、风险承受，现在要在他真正做决定之前，把买入后的规则定下来。

## 开场话术

> "在你决定买之前，我们想清楚买入之后怎么办，这样你才不会在波动中慌乱。几个问题："

## 纪律1：买入逻辑锚点

**话术**：
> "1. 你现在的买入逻辑是什么？什么情况下你会觉得这个逻辑不成立了？"

**用户可能回答**：
- "估值低，赌轮动补涨"
- "消费长期看多，现在便宜"
- "政策在刺激消费"

**需要引导用户明确**：
- 买入逻辑：用一句话概括
- 逻辑失效信号：什么情况下逻辑不成立了

**示例引导**：
> "你说的是'{用户回答}'，那我帮你明确一下：如果出现{反向信号}，说明这个逻辑可能不成立了，对吧？"

**记录到状态**：
```json
{
  "logic_anchor": {
    "buy_logic": "估值低+赌消费轮动补涨",
    "invalid_signals": ["基本面持续恶化", "消费数据持续下滑"]
  }
}
```

## 纪律2：风险底线

**话术**：
> "2. 你能承受的最大浮亏是多少？单行业仓位最高控制在总资金的百分之多少？"

**需要引导用户明确**：
- 单行业仓位上限（通常建议 10-20%）
- 最大可承受浮亏比例
- 触发后的动作

**关键说明**：
> "这不是让你到时候机械式清仓。风险底线触发的是'审视和行动'：如果只是市场情绪导致的下跌，逻辑还在，你可以选择减仓部分、保留底仓观望。"

**记录到状态**：
```json
{
  "risk_bottom_line": {
    "position_limit": "20%",
    "max_loss_tolerance": "25%",
    "trigger_action": "审视并决定是否减仓"
  }
}
```

## 纪律3：止盈策略

**话术**：
> "3. 如果涨了，你打算一次性走还是分批走？"

**默认引导方向**：分批止盈

> "一般建议分批止盈，比如涨到X%卖1/3，涨到Y%再卖1/3，剩余继续持有。除非你的仓位特别小，那一次性走也可以。"

**用户需要确定**：
- 是否分批
- 分批的话，每档的百分比和卖出比例

**记录到状态**：
```json
{
  "take_profit": {
    "method": "分批",
    "steps": ["涨15%卖1/3", "涨25%再卖1/3", "剩余持有"]
  }
}
```

## 纪律4：补仓规则

**话术**：
> "4. 如果跌了，什么情况下你会考虑补仓？最多补到什么仓位？"

**必须同时满足三个条件才能补仓**：

| 条件 | 说明 |
|------|------|
| 买入逻辑仍然成立 | 基本面没恶化，只是市场情绪导致下跌 |
| 仓位有空间 | 当前仓位 + 补仓后不超上限 |
| 有可用资金 | 不因为补仓而加杠杆或动用生活资金 |

**用户需要确定**：
- 补仓条件（三项都要确认）
- 最多补到什么仓位

**记录到状态**：
```json
{
  "add_position": {
    "conditions": ["逻辑仍在", "仓位未超限", "有可用资金"],
    "max_position_after_add": "15%"
  }
}
```

## 收束话术

四条纪律问完后：

> "这四个问题想清楚，你买入之后就不慌了。"
>
> "接下来我帮你整理一下详细数据，看完你再做决定。"

然后等待小研的详细数据报告就绪，进入详细数据报告阶段。参见 [detail_report.md](detail_report.md)。

## 注意事项

- **仓位高于一切** — 四条纪律必须结合用户仓位
- 如果用户之前的回答已经暗示了某些纪律的答案（如追问3中说了"能忍20%"），直接确认而不重复追问
- 四条纪律的内容最终会写入执行计划文档
- 用户可以随时修改自己定的参数，不做强制
