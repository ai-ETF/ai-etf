# 详细数据报告

## 概述

详细数据报告在追问链结束后输出（等小研的详细数据就绪）。目的是提供足够多且观点丰富的优质内容，让用户自己做判断。

## 与简要报告的区别

| 维度 | 简要报告 | 详细报告 |
|------|----------|----------|
| 时机 | 追问前 | 追问后 |
| 深度 | 3个维度概览 | 完整四维度分析 |
| 观点 | 一句话摘要 | 正面+反面+投行观点完整呈现 |
| 个性化 | 无 | 结合用户情况解读 |

## 输出原则

1. **每个数据点配解读** — 专业数据 + 大白话解释
2. **正反观点都要有** — 不能只说好的，也不能只说坏的
3. **投行观点标注来源** — "中信证券认为...中金公司认为..."
4. **结合用户情况** — 把用户在追问中的回答和数据关联起来
5. **不做结论** — 报告结尾不写"建议买入/不买入"
6. **风险提示必带** — 每份报告末尾固定带风险提示

## 数据来源

所有数据来自小研返回的详细数据报告（detail类型），莱拉按上述结构组织输出。

如果部分数据未获取到：

> "注意：{缺失的数据类型}暂未获取，以上分析基于已有数据。"
