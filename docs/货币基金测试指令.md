## 二、核心测试：新用户自动购入货基

用全新 user_id 测试（改 `test-user-mf-001` 后缀可换新人）：

```bash
USER="test-user-mf-001"

# 1. 查看账户（首次访问 → 自动创建账户 + 申购货基 + 立即确认）
curl -s -H "X-User-Id: $USER" "$BASE/test/account" | python3 -m json.tool
```

**预期结果：**
- `cash` 接近 0（资金已全部申购货基）
- `total_assets` ≈ 100000
- `position_count` = **1**

```bash
# 2. 查看持仓 → 应持有天弘余额宝约 100000 份
curl -s -H "X-User-Id: $USER" "$BASE/test/positions?include_quote=true" | python3 -m json.tool
```

**预期结果：**
- `fund_code` = "000198"
- `fund_name` = "天弘余额宝货币市场基金"
- `quantity` ≈ 100000 份
- `cost_price` ≈ 当前合成净值（如 1.0560）
- `pnl` ≥ 0（日日正收益）

## 四、手动赎回货基

先确认 pending 订单，再赎回：

```bash

# 1. 确认 pending 订单
curl -s -X POST "$BASE/test/confirm-pending" \
  -H "X-User-Id: $USER" | python3 -m json.tool

# 2. 查看当前持仓份额
curl -s -H "X-User-Id: $USER" "$BASE/test/positions?include_quote=true" | python3 -m json.tool

  -H "Content-Type: application/json" \

  -d '{"fund_code":"000198","quantity":500}' | python3 -m json.tool
```

**预期结果：**
- `success: true`
- `fee` = 0（赎回费全免）

## 七、边界测试

### 7.1 重复查看账户（不会再申购）

```bash

# 多次调用 account，position_count 始终为 1

curl -s -H "X-User-Id: $USER" "$BASE/test/account" | python3 -m json.tool | grep position_count
```

### 7.2 未确认申购不可赎回

```bash
USER="test-user-mf-002"

# 1. 新用户 → 自动申购已确认，直接追加一笔手动申购
curl -s -X POST "$BASE/test/apply-purchase" \
  -H "Content-Type: application/json" \
  -H "X-User-Id: $USER" \
  -d '{"fund_code":"000198","amount":1000}' | python3 -m json.tool

# 2. 尝试赎回（pending 未确认，会被拦截）
curl -s -X POST "$BASE/test/apply-redeem" \
  -H "Content-Type: application/json" \
  -H "X-User-Id: $USER" \
  -d '{"fund_code":"000198","quantity":100}' | python3 -m json.tool
```

**预期拦截：** "存在待确认的申购订单，份额确认前无法赎回"
