# 货币基金（000198）功能测试

## 前置条件

1. 在 Supabase SQL Editor 执行 `sql/fund_fee_rules_seed.sql`（或单独执行 000198 的 INSERT）
2. 重启后端服务

## 环境配置

```bash
HOST="http://localhost:8000"
BASE="$HOST/api/portfolio"
```

## 获取 JWT Token

```bash
TOKEN=$(curl -s -X POST "$HOST/api/secure-chat/login" \
  -H "Content-Type: application/json" \
  -d '{"email":"lpqst@outlook.com","password":"ai-ETF"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['access_token'])")

AUTH="Authorization: Bearer $TOKEN"
echo "Token: ${TOKEN:0:20}..."
```

> **注意**：以下所有请求都用 JWT Token 认证。自动购入测试需要一个**未交易过的新账号**（见第二节说明）。

---

## 一、查看账户与持仓

```bash
# 1. 查看账户概况
curl -s -H "$AUTH" "$BASE/account" | python3 -m json.tool

# 2. 查看持仓列表
curl -s -H "$AUTH" "$BASE/positions?include_quote=true" | python3 -m json.tool
```

---

## 二、自动购入货基（新用户）

> 只有**从未交易过的新账号**才会触发自动购入。如果你已交易过，换一个新邮箱注册后拿新 JWT 测试。

新用户首次访问账户 → 自动创建账户 + 申购货基 + 立即确认：

```bash
# 用新邮箱注册
curl -s -X POST "$HOST/api/secure-chat/register" \
  -H "Content-Type: application/json" \
  -d '{"email":"test-mf@outlook.com","password":"ai-ETF","name":"货基测试"}'

# 用新账号登录拿 Token
TOKEN_NEW=$(curl -s -X POST "$HOST/api/secure-chat/login" \
  -H "Content-Type: application/json" \
  -d '{"email":"test-mf@outlook.com","password":"ai-ETF"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['access_token'])")
AUTH_NEW="Authorization: Bearer $TOKEN_NEW"

# 首次查看账户 → 自动购入货基
curl -s -H "$AUTH_NEW" "$BASE/account" | python3 -m json.tool
```

**预期结果：**
- `cash` 接近 0（资金已全额申购货基）
- `total_assets` ≈ 100000
- `position_count` = **1**

```bash
# 查看持仓 → 应持有天弘余额宝约 100000 份
curl -s -H "$AUTH_NEW" "$BASE/positions?include_quote=true" | python3 -m json.tool
```

**预期结果：**
- `fund_code` = "000198"，`fund_name` = "天弘余额宝货币市场基金"
- `quantity` ≈ 100000 份
- `pnl` ≥ 0（日日正收益）

## 三、手动申购货基

```bash
# 申购 5000 元货基（无申购费）
curl -s -X POST "$BASE/apply-purchase" \
  -H "Content-Type: application/json" \
  -H "$AUTH" \
  -d '{"fund_code":"000198","amount":5000}' | python3 -m json.tool
```

**预期结果：**
- `success: true`
- `fee` = 0（申购费全免）
- 资金冻结，等待 T+1 确认

---

## 四、手动赎回货基

先确认 pending 订单，再赎回：

```bash
# 1. 手动确认 pending 订单
curl -s -X POST "$BASE/confirm-pending" -H "$AUTH" | python3 -m json.tool

# 2. 查看持仓份额（确认需要赎回多少）
curl -s -H "$AUTH" "$BASE/positions?include_quote=true" | python3 -m json.tool

# 3. 赎回 500 份（赎回费为 0）
curl -s -X POST "$BASE/apply-redeem" \
  -H "Content-Type: application/json" \
  -H "$AUTH" \
  -d '{"fund_code":"000198","quantity":500}' | python3 -m json.tool
```

**预期结果：**
- `success: true`，`fee` = 0

## 七、边界测试

### 7.1 重复查看账户（不会再申购）

```bash
curl -s -H "$AUTH" "$BASE/account" | python3 -m json.tool | grep position_count
curl -s -H "$AUTH" "$BASE/account" | python3 -m json.tool | grep position_count
# position_count 应该一致
```

### 7.2 未确认申购不可赎回

```bash
# 先申购一笔（不确认）
curl -s -X POST "$BASE/apply-purchase" \
  -H "Content-Type: application/json" \
  -H "$AUTH" \
  -d '{"fund_code":"000198","amount":1000}' | python3 -m json.tool

# 尝试赎回 → 应被拦截
curl -s -X POST "$BASE/apply-redeem" \
  -H "Content-Type: application/json" \
  -H "$AUTH" \
  -d '{"fund_code":"000198","quantity":100}' | python3 -m json.tool
```

**预期拦截：** `"存在待确认的申购订单，份额确认前无法赎回"`

