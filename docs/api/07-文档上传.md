# 07 文档上传（/api/upload）

文档摄取与处理接口。全部为公开接口。

## 接口速查

| 方法 | 路径 | 认证 |
|------|------|:---:|
| POST | `/api/upload` | - |
| POST | `/api/upload/process-file-from-edge` | - |
| GET | `/api/upload/health` | - |

## 1. 上传文档

**方法 / 路径：** `POST /api/upload`（公开）

**请求体：**

| 字段 | 类型 | 必需 | 说明 |
|------|------|:---:|------|
| url | string | ✅ | 文档下载 URL（如 PDF） |
| source | string | ✅ | 来源标记（如 `test`） |

```bash
curl -s -X POST "$API/api/upload" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/document.pdf", "source": "test"}' | python3 -m json.tool
```

**响应要点：** `success`、`doc_id`。

## 2. 处理 Edge Function 文件

**方法 / 路径：** `POST /api/upload/process-file-from-edge`（公开）

**说明：** 专门用于处理来自 Edge Function 的文件处理请求。

**请求体：**

| 字段 | 类型 | 必需 | 说明 |
|------|------|:---:|------|
| file_id | string | ✅ | 文件 ID |
| user_id | string | ✅ | 用户 ID |
| download_url | string | ✅ | 文件下载 URL |
| doc_type | string | ❌ | 文档类型（默认 `general_document`） |
| parse_strategy | object | ❌ | 解析策略 |

```bash
curl -s -X POST "$API/api/upload/process-file-from-edge" \
  -H "Content-Type: application/json" \
  -d '{
    "file_id": "file-123",
    "user_id": "user-456",
    "download_url": "https://example.com/document.pdf",
    "doc_type": "general_document",
    "parse_strategy": {}
  }' | python3 -m json.tool
```

**响应要点：** `success`、`document_id`。缺少 `file_id` / `user_id` / `download_url` 任一返回 400。

## 3. 健康检查

**方法 / 路径：** `GET /api/upload/health`（公开）

```bash
curl -s "$API/api/upload/health" | python3 -m json.tool
# {"status": "healthy", "service": "document-processing"}
```
