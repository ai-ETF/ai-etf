# 02 对话 & 会话管理

LLM 流式对话与会话管理接口（`/api/secure-chat`）。除登录外均需 JWT，`user_id` 从 token 自动读取，**不要在请求体中传**。

## 前置条件

```bash
# 先按 01-基础与认证.md 获取 $API / $TOKEN / $AUTH
```

## 接口速查

| 方法 | 路径 | 认证 |
|------|------|:---:|
| POST | `/api/secure-chat` | 🔒 |
| GET | `/api/secure-chat/chats` | 🔒 |
| GET | `/api/secure-chat/chats/{chat_id}/messages` | 🔒 |
| DELETE | `/api/secure-chat/chats/{chat_id}` | 🔒 |

## 1. 发送消息（流式 SSE）

**方法 / 路径：** `POST /api/secure-chat`（🔒）

**说明：** 返回 SSE 流。不传 `chat_id` 自动创建新会话；传 `chat_id` 则加载历史上下文继续对话。

**curl 示例：**

```bash
# 发送第一条消息（创建新会话）
curl -X POST "$API/api/secure-chat" \
  -H "Content-Type: application/json" \
  -H "$AUTH" \
  -d '{"question": "你好，请问 ETF 是什么？"}'

# 在已有会话中继续（用上次返回的 chat_id）
curl -X POST "$API/api/secure-chat" \
  -H "Content-Type: application/json" \
  -H "$AUTH" \
  -d '{"question": "能详细解释一下吗？", "chat_id": "<CHAT_ID>"}'
```

**请求体：**

| 字段 | 类型 | 必需 | 说明 |
|------|------|:---:|------|
| question | string | ✅ | 用户问题 |
| chat_id | string | ❌ | 会话 ID，不传则新建会话 |

**SSE 事件：** `token`（生成中的 token）→ `done`（结束，含 `chat_id`）→ 异常时 `error`。

## 2. 获取会话列表

**方法 / 路径：** `GET /api/secure-chat/chats?limit=50`（🔒）

```bash
curl -s "$API/api/secure-chat/chats?limit=50" \
  -H "$AUTH" | python3 -m json.tool
```

**响应示例：**

```json
{
  "total": 2,
  "chats": [
    {
      "id": "chat-uuid",
      "user_id": "user-uuid",
      "title": "你好，请问 ETF 是什么...",
      "created_at": "2026-01-01T00:00:00Z",
      "updated_at": "2026-01-01T00:01:00Z"
    }
  ]
}
```

## 3. 获取会话消息历史

**方法 / 路径：** `GET /api/secure-chat/chats/{chat_id}/messages?limit=100`（🔒）

```bash
curl -s "$API/api/secure-chat/chats/<CHAT_ID>/messages?limit=100" \
  -H "$AUTH" | python3 -m json.tool
```

**响应示例：**

```json
{
  "chat_id": "chat-uuid",
  "chat_title": "你好，请问 ETF 是什么...",
  "total": 4,
  "messages": [
    {
      "id": "msg-uuid",
      "chat_id": "chat-uuid",
      "role": "user",
      "content": "你好，请问 ETF 是什么？",
      "created_at": "2026-01-01T00:00:00Z"
    }
  ]
}
```

## 4. 删除会话

**方法 / 路径：** `DELETE /api/secure-chat/chats/{chat_id}`（🔒）

```bash
curl -s -X DELETE "$API/api/secure-chat/chats/<CHAT_ID>" \
  -H "$AUTH" | python3 -m json.tool
```

**响应示例：**

```json
{
  "message": "会话已删除",
  "chat_id": "chat-uuid"
}
```

## 完整流程示例

```bash
# 1. 登录拿 token
TOKEN=$(curl -s -X POST "$API/api/secure-chat/login" \
  -H "Content-Type: application/json" \
  -d "{\"email\":\"$EMAIL\",\"password\":\"$PASSWORD\"}" \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['access_token'])")
AUTH="Authorization: Bearer $TOKEN"

# 2. 发第一条消息 → 记下返回的 chat_id
curl -s -X POST "$API/api/secure-chat" \
  -H "Content-Type: application/json" -H "$AUTH" \
  -d '{"question": "你好，请问 ETF 是什么？"}'

# 3. 用 chat_id 继续对话
CHAT_ID="<上一步返回的chat_id>"
curl -s -X POST "$API/api/secure-chat" \
  -H "Content-Type: application/json" -H "$AUTH" \
  -d "{\"question\": \"能详细解释一下吗？\", \"chat_id\": \"$CHAT_ID\"}"

# 4. 会话列表 → 消息历史 → 删除会话
curl -s "$API/api/secure-chat/chats" -H "$AUTH"
curl -s "$API/api/secure-chat/chats/$CHAT_ID/messages" -H "$AUTH"
curl -s -X DELETE "$API/api/secure-chat/chats/$CHAT_ID" -H "$AUTH"
```
