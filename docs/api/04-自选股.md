# 04 自选股（/api/watchlist）

自选股管理接口。除健康检查外均需 JWT，`user_id` 从 token 自动读取，**不要在请求体中传**。

## 前置条件

```bash
# 先按 01-基础与认证.md 获取 $API / $AUTH
```

## 接口速查

| 方法 | 路径 | 认证 |
|------|------|:---:|
| POST | `/api/watchlist/add` | 🔒 |
| DELETE | `/api/watchlist/remove` | 🔒 |
| GET | `/api/watchlist/list` | 🔒 |
| DELETE | `/api/watchlist/clear` | 🔒 |
| GET | `/api/watchlist/health` | - |

## 1. 添加自选股

**方法 / 路径：** `POST /api/watchlist/add`（🔒）

```bash
curl -s -X POST "$API/api/watchlist/add" \
  -H "Content-Type: application/json" \
  -H "$AUTH" \
  -d '{"fund_code": "512890", "fund_name": "红利低波ETF华泰柏瑞"}' | python3 -m json.tool

curl -s -X POST "$API/api/watchlist/add" \
  -H "Content-Type: application/json" \
  -H "$AUTH" \
  -d '{"fund_code": "510300", "fund_name": "沪深300ETF华泰柏瑞"}' | python3 -m json.tool
```

**请求体：**

| 字段 | 类型 | 必需 | 说明 |
|------|------|:---:|------|
| fund_code | string | ✅ | 基金代码 |
| fund_name | string | ✅ | 基金名称 |

## 2. 查询自选股列表（含实时行情）

**方法 / 路径：** `GET /api/watchlist/list`（🔒）

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| include_quote | bool | true | 是否附带实时行情 |

```bash
curl -s "$API/api/watchlist/list?include_quote=true" \
  -H "$AUTH" | python3 -m json.tool
```

## 3. 移除自选股

**方法 / 路径：** `DELETE /api/watchlist/remove`（🔒）

```bash
curl -s -X DELETE "$API/api/watchlist/remove" \
  -H "Content-Type: application/json" \
  -H "$AUTH" \
  -d '{"fund_code": "510300"}' | python3 -m json.tool
```

## 4. 清空自选股

**方法 / 路径：** `DELETE /api/watchlist/clear`（🔒）

```bash
curl -s -X DELETE "$API/api/watchlist/clear" \
  -H "$AUTH" | python3 -m json.tool
```

## 5. 健康检查

**方法 / 路径：** `GET /api/watchlist/health`（公开）

```bash
curl -s "$API/api/watchlist/health" | python3 -m json.tool
```
