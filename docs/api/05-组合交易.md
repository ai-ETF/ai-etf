# 05 组合交易（/api/portfolio）

场外基金模拟交易：申购、赎回、持仓、账户、流水、快照、定投。正式端点需 JWT；`test/*` 开发端点免 JWT（仅非生产环境可用），用 `X-User-Id` header 指定用户。

## 前置条件

```bash
# 先按 01-基础与认证.md 获取 $API / $TOKEN / $AUTH
```

## 1. 账户概况

**方法 / 路径：** `GET /api/portfolio/account`（🔒）

```bash
curl -s "$API/api/portfolio/account" -H "$AUTH" | python3 -m json.tool
```

**响应要点：** `cash`（可用现金）、`frozen_cash`（冻结资金）、`position_value`（持仓市值）、`total_assets`（总资产）、`total_pnl`（总盈亏）、`total_return_rate`（总收益率）、`position_count`。

## 2. 持仓列表

**方法 / 路径：** `GET /api/portfolio/positions`（🔒）

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| include_quote | bool | true | 是否按实时行情计算市值和盈亏 |

```bash
curl -s "$API/api/portfolio/positions?include_quote=true" -H "$AUTH" | python3 -m json.tool
```

## 3. 申购（按金额）

**方法 / 路径：** `POST /api/portfolio/apply-purchase`（🔒）

**请求体：**

| 字段 | 类型 | 必需 | 说明 |
|------|------|:---:|------|
| fund_code | string | ✅ | 基金代码（须在白名单内） |
| amount | number | ✅ | 申购金额（元） |
| price | number | ❌ | 净值，不传自动获取；自动获取失败时可手动指定 |

```bash
# A 股联接基金（T+1 确认）——110020 易方达沪深300ETF联接A，费率 <100万 0.12%
curl -s -X POST "$API/api/portfolio/apply-purchase" \
  -H "Content-Type: application/json" -H "$AUTH" \
  -d '{"fund_code":"110020","amount":1000}' | python3 -m json.tool

# C 类基金（免申购费）——001595 天弘中证银行ETF联接C
curl -s -X POST "$API/api/portfolio/apply-purchase" \
  -H "Content-Type: application/json" -H "$AUTH" \
  -d '{"fund_code":"001595","amount":2000}' | python3 -m json.tool

# QDII 基金（T+2 确认，T+7 到账）——000071 华夏恒生ETF联接A
curl -s -X POST "$API/api/portfolio/apply-purchase" \
  -H "Content-Type: application/json" -H "$AUTH" \
  -d '{"fund_code":"000071","amount":500}' | python3 -m json.tool

# 手动指定净值（无法自动获取净值时）
curl -s -X POST "$API/api/portfolio/apply-purchase" \
  -H "Content-Type: application/json" -H "$AUTH" \
  -d '{"fund_code":"110020","amount":1000,"price":1.85}' | python3 -m json.tool
```

## 5. 交易流水

**方法 / 路径：** `GET /api/portfolio/trade-flow`（🔒）

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| page | int | 1 | 页码 |
| page_size | int | 20 | 每页条数 |
| fund_code | string | - | 按基金筛选 |
| direction | string | - | `buy` / `sell` 按方向筛选 |

```bash
# 全部流水
curl -s "$API/api/portfolio/trade-flow?page=1&page_size=20" -H "$AUTH" | python3 -m json.tool

# 按基金筛选
curl -s "$API/api/portfolio/trade-flow?fund_code=110020&page=1&page_size=10" -H "$AUTH" | python3 -m json.tool

# 按方向筛选
curl -s "$API/api/portfolio/trade-flow?direction=buy&page=1&page_size=10" -H "$AUTH" | python3 -m json.tool
```

> 只有已确认的订单才会写入流水；pending 订单确认后才有记录。

## 9. 余额理财开关（自动购入货基）

**方法 / 路径：** `GET/POST /api/portfolio/auto-invest/config`（🔒）

```bash
# 查询开关状态
curl -s "$API/api/portfolio/auto-invest/config" -H "$AUTH" | python3 -m json.tool

# 设置开关 + 预留金额（元）
curl -s -X POST "$API/api/portfolio/auto-invest/config" \
  -H "Content-Type: application/json" -H "$AUTH" \
  -d '{"enabled": true, "reserve": 1000}' | python3 -m json.tool
```

**请求体：** `enabled`（bool，必需，是否开启）、`reserve`（number，默认 0，预留金额）。

> 余额理财会把闲置现金自动申购货基（000198 天弘余额宝）。新用户首次访问 `account` 时会自动创建账户 + 申购货基 + 立即确认。

## 常见问题

**Q: 申购显示「无法获取净值」？**
A: 数据源没有该基金的净值数据。可以用 `price` 参数手动指定净值。

**Q: 赎回被拦截「存在待确认的申购订单」？**
A: pending 订单确认前无法赎回同基金。先调 `/confirm-pending` 确认。

**Q: 交易流水为空？**
A: 只有已确认的订单才写入流水表，pending 订单确认后才有记录。

**Q: 非交易时间申购？**
A: 系统自动识别，显示「下一交易日受理」。资金冻结，等确认日才扣款建仓。
