## 3. 申购（按金额）

**方法 / 路径：** `POST /api/portfolio/apply-purchase`（🔒）

**请求体：**

| 字段 | 类型 | 必需 | 说明 |
|------|------|:---:|------|
| fund_code | string | ✅ | 基金代码（须在白名单内） |
| amount | number | ✅ | 申购金额（元） |
| price | number | ❌ | 净值，不传自动获取；自动获取失败时可手动指定 |

```bash

  -H "Content-Type: application/json" -H "$AUTH" \
  -d '{"fund_code":"110020","amount":1000}' | python3 -m json.tool

  -H "Content-Type: application/json" -H "$AUTH" \
  -d '{"fund_code":"001595","amount":2000}' | python3 -m json.tool
```

## 10. 基金列表（可交易场外基金）

**方法 / 路径：** `GET /api/portfolio/funds`（🔒）

查询白名单内可交易的场外基金，供前端选基金下单。**查不到的基金下单会被直接拒绝**（白名单机制）。
注意**「在列表里」≠「当前能买」**：暂停申购 / 封闭期等状态的基金仍在列表中（已持有份额可赎回），能否买入须看 `subscribe_status`，详见下方「支持的白名单基金」。

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| keyword | string | - | 关键词，同时匹配基金代码与名称（模糊、不区分大小写）。含标点会被自动剔除 |
| page | int | 1 | 页码，从 1 开始 |
| page_size | int | 20 | 每页条数，上限 100 |

```bash
# 浏览全部（默认返回 20 条）
curl -s "$API/api/portfolio/funds" -H "$AUTH" | python3 -m json.tool

# 搜「光伏」，前端下拉框场景
curl -s "$API/api/portfolio/funds?keyword=光伏&page_size=10" -H "$AUTH" | python3 -m json.tool

# 按代码精确搜
curl -s "$API/api/portfolio/funds?keyword=110020" -H "$AUTH" | python3 -m json.tool
```

**响应要点：** `total`（匹配总数）、`page`、`page_size`、`items[]`。每项含 `fund_code`、`fund_name`、`fund_type`（恒为 `of`，场外）、`share_class`（份额类别 A/C 等）、`min_purchase_amount`、`max_purchase_amount`（单日累计申购上限，为空表示无限额）、`subscribe_status`（申购状态：`开放申购` / `限大额` 可申购，`暂停申购` / `封闭期` 等只能赎回，为空表示存量行按可申购处理）、`confirm_delay`（T+N 确认）、`redeem_settle_delay`（T+N 到账）、运作费率 `management_fee_rate` / `custody_fee_rate` / `sales_service_fee_rate`（小数，`0.005` = 0.5%），以及风险画像 `risk_level` / `risk_label` 与四维分（`breadth_score` / `volatility_score` / `market_score` / `board_score`，未配置的基金为空）。

> 费率分档体积较大，**不在列表接口返回**，需下单前展示费率的场景请调第 11 节详情接口。

## 11. 基金详情（含费率分档）

**方法 / 路径：** `GET /api/portfolio/funds/{fund_code}`（🔒）

返回该基金的完整交易规则，可直接用于前端算费展示。不在白名单内返回 **404**。

```bash
curl -s "$API/api/portfolio/funds/110020" -H "$AUTH" | python3 -m json.tool

# 不在白名单的基金 → 404 {"detail": "暂不支持基金 999999 的交易"}
curl -s "$API/api/portfolio/funds/999999" -H "$AUTH" | python3 -m json.tool
```

**响应要点：** 在第 10 节列表项字段之上，追加：

| 字段 | 说明 |
|------|------|
| `commission_rate` | 平台佣金费率（0.0003） |
| `purchase_fee_tiers` | 申购费分档：`[{"rate": 0.0012, "amount": 1000000}, ..., {"rate": 0, "fixed_fee": 1000}]`。`amount` 为金额上界（不含），`inclusive=true` 表示含边界；`fixed_fee` 为固定费用档 |
| `redemption_fee_tiers` | 赎回费分档：`[{"days": 7, "rate": 0.015}, ..., {"days": 730, "rate": 0.0, "inclusive": true}]`。`days` 为持有天数上界（不含），`inclusive=true` 表示含边界 |

> **费率取天天基金的平台优惠费率**（页面「原费率\|优惠费率」的后者），与原费率不同。

## 支持的白名单基金

白名单就是 `fund_fee_rules` 表：**表里有记录的基金才能交易**，查不到直接拒单（`暂不支持基金 xxx 的交易`）。`fund_risk_profiles` 提供对应的风险画像，仅用于下单前的风险提示，不阻断交易。

- **范围**：场外 **ETF 联接基金**，当前约 2286 只。实时可用列表以第 10 节 `GET /api/portfolio/funds` 为准，**不要把基金代码写死在前端**。
- **同步机制**：`server/services/fund_catalog_sync.py` 每天 02:17 全量抓取天天基金的费率（申购/赎回分档、运作费率、申购起点）与移动端基础信息，按关键词规则推导四维风险分，幂等 upsert 进上面两张表。
- **准入条件**（不满足则不写入，宁可不支持也不用默认费率兜底）：
  - 申购状态能抓到（**抓不到即整只跳过**，宁可不支持也不凭残缺数据写入）
  - 申购费与赎回费分档都能抓到且非空
  - 排除：货币基金、外币份额（美元/现汇/现钞）、后端收费份额、定开/封闭/持有期份额
- **「在目录里」≠「能买」**：目录里可能出现**暂停申购 / 封闭期 / 认购期**的基金 ——
  它们是从「开放申购」转为不可申购**之后仍然保留的行**，写库是为了让状态随同步更新、
  且已持有的份额仍能赎回（赎回不受申购状态限制）。这些基金的买入请求会被拒：
  `该基金当前「暂停申购」，暂不接受申购（已持有份额仍可赎回）`。
  前端应据此灰置买入按钮，而不是把它们从列表里过滤掉。
- **限大额基金**：状态为「限大额」的基金可以交易，但有**单日累计申购上限**（落在 `max_purchase_amount` 字段，取自天天基金 `MAXSG`，随每日同步刷新）。下单校验的是**同一证券交易日（T 日）的累计申购金额**（含 pending 单），超过即拒单 —— 拆成多笔小额下单同样会被拦住。
  - 若同步时 `MAXSG` 解析失败（状态为「限大额」但上限为空），该行会带着 `subscribe_status="限大额"`、`max_purchase_amount=null` 落库，**买入被拒**（`该基金限额信息暂不可用…`）但赎回正常。这类记录即运维需人工干预的清单：
    ```sql
    SELECT fund_code, fund_name, subscribe_status FROM fund_fee_rules
    WHERE subscribe_status = '限大额' AND max_purchase_amount IS NULL;
    ```
- **T+N 口径**：按类别判定，非逐只抓页面 —— 境内基金 T+1 确认 / T+3 到账；QDII 跨境 T+2 / T+7；货基 T+1 / T+1。
- **保留策略**：同步与现有白名单**求并集**，已支持的基金不会因更名而掉出（如 161831 现已更名为「银华恒生国企指数(QDII-LOF)A」，名称中已无「联接」二字）。

## 常见问题

**Q: 申购显示「无法获取净值」？**
A: 数据源没有该基金的净值数据。可以用 `price` 参数手动指定净值。

**Q: 赎回被拦截「存在待确认的申购订单」？**
A: pending 订单确认前无法赎回同基金。先调 `/confirm-pending` 确认。

**Q: 交易流水为空？**
A: 只有已确认的订单才写入流水表，pending 订单确认后才有记录。

**Q: 非交易时间申购？**
A: 系统自动识别，显示「下一交易日受理」。资金冻结，等确认日才扣款建仓。

**Q: 下单提示「暂不支持基金 xxx 的交易」？**
A: 该基金根本不在目录里。可能原因：申购状态抓取失败、申赎费率分档抓取不全，或属于不纳入的类型（货币基金、外币份额、后端收费、定开/封闭/持有期）。先用 `GET /api/portfolio/funds?keyword=xxx` 确认。
注意与下一条的区别：**如果它在目录里但状态不可申购**，提示会是「该基金当前『暂停申购』…」。

**Q: 下单提示「该基金当前『xxx』，暂不接受申购」？**
A: 该基金在目录里（能查到、能赎回），但当前状态不是「开放申购」或「限大额」。目录保留它是为了让同步能持续更新状态、并保证已持有的份额可以正常赎回。查看详情接口的 `subscribe_status` 字段即可确认。

**Q: 下单提示「该基金限额信息暂不可用…」？**
A: 该基金状态为「限大额」，但每日同步没能取到它的单日申购上限（数据源字段解析失败）。系统不把「上限未知」当作「无限额」，因此暂时拒绝买入、赎回不受影响，待次日同步重试恢复。运维可用 `SELECT fund_code FROM fund_fee_rules WHERE subscribe_status='限大额' AND max_purchase_amount IS NULL;` 查出这类基金。

**Q: 提示「合计超过该基金单日累计申购上限 X 元」？**
A: 该基金处于「限大额」状态（详情接口的 `max_purchase_amount` 就是该上限）。校验的是**同一交易日（T 日）的累计申购金额**，含已提交待确认（pending）的单，因此拆成多笔小额下单同样会被拦住。被撤销、被拒的单不占用额度。

注意「单日」指**证券交易日**，不是自然日：法定节假日、以及交易日 15:00 之后下的单，都会顺延到下一个交易日受理，**全部计入那一个交易日**。例如国庆 7 天里每天下 100 元，7 笔会归集到节后第一个交易日，合计 700 元 —— 若上限 1000 元则全部通过，若上限 500 元则只有前几笔能成交。

**Q: 列表里的费率和我看到的原费率不一样？**
A: 系统采用天天基金的**平台优惠费率**（页面「原费率\|优惠费率」的后者），因此比基金合同上的原费率低。
