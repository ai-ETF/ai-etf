# 01 基础 & 认证

健康检查与登录接口。**登录是全局唯一的认证入口**，其余模块的 `$TOKEN` 均从这里获取。

## 环境变量

```bash
API="https://ai-etf.xyz"           # 远程（HTTPS）；本地改为 http://localhost:8000
EMAIL="<你的邮箱>"
PASSWORD="<你的密码>"
```

## 接口速查

| 方法 | 路径 | 认证 |
|------|------|:---:|
| GET | `/` | - |
| GET | `/api/test/hello` | - |
| POST | `/api/secure-chat/register` | - |
| POST | `/api/secure-chat/login` | - |

## 1. 服务健康检查

**方法 / 路径：** `GET /`（公开）

```bash
curl -s "$API/" | python3 -m json.tool
```

## 2. 测试端点

**方法 / 路径：** `GET /api/test/hello`（公开）

```bash
curl -s "$API/api/test/hello" | python3 -m json.tool
```

## 3. 登录获取 JWT

**方法 / 路径：** `POST /api/secure-chat/login`（公开，全站唯一登录入口）

**说明：** 校验邮箱密码（Supabase Auth），返回 `access_token`。所有需认证接口在 Header 携带 `Authorization: Bearer <token>`。

**curl 示例：**

```bash
# 方式一：直接看完整响应
curl -X POST "$API/api/secure-chat/login" \
  -H "Content-Type: application/json" \
  -d "{\"email\":\"$EMAIL\",\"password\":\"$PASSWORD\"}" | python3 -m json.tool

# 方式二：只提取 token 写入变量（后续文档统一用 $TOKEN / $AUTH）
TOKEN=$(curl -s -X POST "$API/api/secure-chat/login" \
  -H "Content-Type: application/json" \
  -d "{\"email\":\"$EMAIL\",\"password\":\"$PASSWORD\"}" \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['access_token'])")
AUTH="Authorization: Bearer $TOKEN"
echo "Token: ${TOKEN:0:20}..."
```

**请求体：**

| 字段 | 类型 | 必需 | 说明 |
|------|------|:---:|------|
| email | string | ✅ | 邮箱 |
| password | string | ✅ | 密码 |

**响应示例：**

```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "token_type": "bearer",
  "user_id": "uuid-string",
  "expires_in": 3600
}
```

> token 有效期 3600 秒（1 小时）。登录失败返回 401「邮箱或密码错误」。

## 4. 注册账号

**方法 / 路径：** `POST /api/secure-chat/register`（公开）

**说明：** 调用 Supabase Auth 注册新用户。当前为 auto-confirm 模式（`enable_confirmations=false`），注册成功即激活并直接返回 `access_token`，前端可用其作为登录态。密码至少 8 位。

**请求体：**

| 字段 | 类型 | 必需 | 说明 |
|------|------|:---:|------|
| email | string | ✅ | 邮箱，格式校验 |
| password | string | ✅ | 密码，至少 8 位 |

**curl 示例：**

```bash
curl -X POST "$API/api/secure-chat/register" \
  -H "Content-Type: application/json" \
  -d "{\"email\":\"$EMAIL\",\"password\":\"$PASSWORD\"}" | python3 -m json.tool
```

**响应示例（auto-confirm 模式，`201`）：**

```json
{
  "success": true,
  "needs_email_confirmation": false,
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "token_type": "bearer",
  "user_id": "uuid-string",
  "expires_in": 3600,
  "message": "注册成功，已自动登录"
}
```

**邮箱确认模式响应（若未来开启 `enable_confirmations`）：** 不返回 token，`needs_email_confirmation=true`，提示用户查收邮件后走登录接口。

**错误：** 邮箱格式非法或密码不足 8 位 → `400`；邮箱已注册 → `409「该邮箱已注册，请直接登录」`；服务异常 → `502`。
