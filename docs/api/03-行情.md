# 03 行情（/api/market）

ETF 行情类接口：实时行情、榜单、K 线、分时、详情、资金流向、搜索筛选。**全部为公开接口，无需 JWT。**

> 提示：HTTPS 下 query 参数含中文时会被拒（`Invalid HTTP request`），需用 `--data-urlencode`；路径中的中文可正常使用。

## 1. 健康检查

**方法 / 路径：** `GET /api/market/health`（公开）

```bash
curl -s "$API/api/market/health" | python3 -m json.tool
# {"status": "ok", "service": "market"}
```

## 2. 实时行情

**方法 / 路径：** `GET /api/market/spot/{fund_code}`（公开）

```bash
curl -s "$API/api/market/spot/512890" | python3 -m json.tool

# 按名称查询
curl -s "$API/api/market/spot/name/红利低波ETF" | python3 -m json.tool
```

**响应要点：** `data` 内含 `code / name / price / change / change_pct / prev_close / open / high / low / volume / amount / turnover_rate / bid_price / ask_price / update_time`。找不到返回 `error` 字段。

## 3. 涨幅榜 / 跌幅榜

**方法 / 路径：** `GET /api/market/ranking`（公开）

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| sort_by | string | `涨跌幅` | 排序字段 |
| top_n | int | 10 | 1–50 |
| order | string | `desc` | `desc`=涨幅榜，`asc`=跌幅榜 |

```bash
# 涨幅榜前 20
curl -s "$API/api/market/ranking?top_n=20&order=desc" | python3 -m json.tool

# 跌幅榜前 10
curl -s "$API/api/market/ranking?top_n=10&order=asc" | python3 -m json.tool
```

## 4. K 线数据

**方法 / 路径：** `GET /api/market/kline/{fund_code}`（公开）

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| period | string | `daily` | `daily` / `weekly` / `monthly` |
| start_date | string | - | 起始日期（如 2024-01-01） |
| end_date | string | - | 结束日期 |
| limit | int | - | 返回条数（1–1000） |

```bash
curl -s "$API/api/market/kline/512890?period=daily&limit=60" | python3 -m json.tool

# 按名称
curl -s "$API/api/market/kline/name/红利低波ETF?period=weekly&limit=30" | python3 -m json.tool
```

**响应要点：** `items[]` 含 `date / open / close / high / low / volume / change_pct`。

## 5. 分时图

**方法 / 路径：** `GET /api/market/intraday/{fund_code}`（公开）

```bash
curl -s "$API/api/market/intraday/512890" | python3 -m json.tool
```

**响应要点：** 含 `date / prev_close / open / current / high / low / change_pct` 与 `items[]`（分时点，`data_source` 区分 real/simulated）。

## 6. ETF 详细信息

## 7. 资金流向

**方法 / 路径：** `GET /api/market/money-flow/{fund_code}`（公开）

```bash
# 单只
curl -s "$API/api/market/money-flow/512890" | python3 -m json.tool
curl -s "$API/api/market/money-flow/name/红利低波ETF" | python3 -m json.tool

curl -s "$API/api/market/money-flow/ranking?top_n=20&order=desc" | python3 -m json.tool
```

## 8. 搜索

**方法 / 路径：** `GET /api/market/search?keyword=...`（公开）

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| keyword | string | 必填 | 名称或代码模糊匹配 |
| top_n | int | 10 | 1–50 |
| include_quote | bool | true | 是否附带实时行情 |

```bash
# 中文关键词需用 --data-urlencode 编码（HTTPS 下原始中文 query 会被拒）
curl -s --get "$API/api/market/search" \
  --data-urlencode "keyword=红利" \
  --data-urlencode "top_n=10" | python3 -m json.tool
```

## 9. 高级筛选

**方法 / 路径：** `POST /api/market/filter`（公开）

**请求体（均为可选，未传字段不参与筛选）：**

```bash
curl -s -X POST "$API/api/market/filter" \
  -H "Content-Type: application/json" \
  -d '{
    "keyword": "ETF",
    "max_fee": 0.5,
    "min_scale_billion": 10,
    "min_return": 0.0,
    "top_n": 20,
    "sort_by": "涨跌幅",
    "sort_order": "desc"
  }' | python3 -m json.tool
```

| 字段 | 类型 | 说明 |
|------|------|------|
| keyword | string | 搜索关键词（默认 `ETF`） |
| max_fee | number | 最大管理费率（%） |
| min_scale_billion / max_scale_billion | number | 规模区间（亿） |
| fund_category | string | 基金分类（指数型-股票/债券/货币/混合） |
| tracking_target | string | 跟踪标的 |
| min_return / max_return | number | 涨跌幅区间（%） |
| has_dividend | bool | 是否分红 |
| top_n | int | 返回条数（默认 20） |
| sort_by | string | 排序字段（默认 `涨跌幅`） |
| sort_order | string | `desc` / `asc` |

## 10. 分类
