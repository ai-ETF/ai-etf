# 06 风险测评（/api/risk）

用户风险画像：获取问卷 → 提交答案 → 查询画像。除健康检查外均需 JWT，`user_id` 从 token 自动读取。

## 前置条件

```bash
# 先按 01-基础与认证.md 获取 $API / $TOKEN / $AUTH
```

## 接口速查

| 方法 | 路径 | 认证 |
|------|------|:---:|
| GET | `/api/risk/health` | - |
| GET | `/api/risk/questionnaire` | 🔒 |
| POST | `/api/risk/submit` | 🔒 |
| GET | `/api/risk/profile` | 🔒 |

## 1. 健康检查

**方法 / 路径：** `GET /api/risk/health`（公开）

```bash
curl -s "$API/api/risk/health" | python3 -m json.tool
# {"status": "ok", "service": "risk"}
```

## 2. 获取问卷

**方法 / 路径：** `GET /api/risk/questionnaire`（🔒）

**说明：** 返回当前最新可用的风险问卷（5 题）。返回的题目**不含** `risk_score`、`weight` 等内部字段，仅含 `question`、`options(text+value)`、`category`。

```bash
curl -s "$API/api/risk/questionnaire" -H "$AUTH" | python3 -m json.tool
```

**响应要点：** `id`（questionnaire_id，提交时要用）、`version`、`questions[]`、`total_questions`。

## 3. 提交问卷答案

**方法 / 路径：** `POST /api/risk/submit`（🔒）

**请求体：**

| 字段 | 类型 | 必需 | 说明 |
|------|------|:---:|------|
| questionnaire_id | string | ✅ | 问卷 ID（来自上一步响应） |
| answers | array | ✅ | `[{question_id, value}]`，5 题缺一不可 |

```bash
curl -s -X POST "$API/api/risk/submit" \
  -H "Content-Type: application/json" \
  -H "$AUTH" \
  -d '{
    "questionnaire_id": "<上一步返回的id>",
    "answers": [
      {"question_id": "q1", "value": "B"},
      {"question_id": "q2", "value": "A"},
      {"question_id": "q3", "value": "C"},
      {"question_id": "q4", "value": "B"},
      {"question_id": "q5", "value": "B"}
    ]
  }' | python3 -m json.tool
```

**响应要点：** `profile.risk_level`（conservative / moderate / aggressive）、`risk_label`（保守型 / 稳健型 / 进取型）、`total_score`、`dimension_scores`、`summary`。

> 同一用户对同一份问卷重复提交会**覆盖旧记录**（返回 200 而非 409）。

## 4. 查询用户画像

**方法 / 路径：** `GET /api/risk/profile`（🔒）

```bash
curl -s "$API/api/risk/profile" -H "$AUTH" | python3 -m json.tool
```

**响应要点：** 未填写时返回 `{"has_profile": false, "profile": null}`；已填写返回 `profile`（含 risk_level、risk_label、total_score、dimension_scores、summary、created_at）。

## 错误处理

| 场景 | HTTP Status | message |
|---|---|---|
| 问卷不存在 | 404 | 问卷不存在或已停用 |
| 答案未覆盖全部题目 | 400 | 请回答全部题目 |
| 答案包含无效选项 | 400 | 问题 {qid} 的选项 {value} 无效 |
| JWT 无效 / 过期 | 401 | 令牌无效或已过期 |
