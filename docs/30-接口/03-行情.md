# 03 行情（/api/market）

基金查询类接口：K 线、分时、详情、搜索。**全部为公开接口，无需 JWT。**

> **2026-10-26 变更（重要）**：产品只做场外基金，场内 ETF 的 30 秒行情轮询已删除，
> 以下接口**已下线**——`/spot/{code}`、`/spot/name/{name}`、`/ranking`、
> `/money-flow/*`、`/filter`、`/categories`、`/category/{cat}`。
> 详情不再返回 `realtime`；搜索/详情只认支持目录（`fund_catalog`）内的场外基金，
> **场内 ETF 代码查不到、也搜不到**（详情返回 404，搜索返回空列表）。
>
> 提示：HTTPS 下 query 参数含中文时会被拒（`Invalid HTTP request`），需用 `--data-urlencode`；路径中的中文可正常使用。

## 1. 健康检查

**方法 / 路径：** `GET /api/market/health`（公开）

```bash
curl -s "$API/api/market/health" | python3 -m json.tool
# {"status": "ok", "service": "market"}
```

## 2. K 线数据

**方法 / 路径：** `GET /api/market/kline/{fund_code}`、`GET /api/market/kline/name/{fund_name}`（公开）

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| period | string | `daily` | `daily` / `weekly` / `monthly`（周/月线由日线重采样） |
| start_date | string | - | 起始日期 `YYYY-MM-DD` |
| end_date | string | - | 结束日期 `YYYY-MM-DD` |
| limit | int | - | 返回最近 N 条（1–1000） |

```bash
curl -s "$API/api/market/kline/512890?period=daily&limit=60" | python3 -m json.tool
```

**响应要点：** `code / name / period / total / items[]`，`items` 每项含
`date / open / close / high / low / volume / amount / amplitude / change_pct / change / turnover_rate`。

## 3. 分时图

**方法 / 路径：** `GET /api/market/intraday/{fund_code}`、`GET /api/market/intraday/name/{fund_name}`（公开）

```bash
curl -s "$API/api/market/intraday/512890" | python3 -m json.tool
```

**响应要点：** `code / name / date / prev_close / open / current / high / low / change_pct / total_volume / total_amount / data_source / items[]`。

- 摘要字段（今开、最高、最低、成交量、成交额、涨跌幅）由**分时点序列自身汇总**，不再依赖实时行情快照。
- `items` 每项：`time（HH:MM）/ price / avg_price / volume / amount / change_pct`。
- 取不到当日分钟线时（非交易日、当日尚无数据、上游不可达）返回 **200 + `items: []`** 与全 0 摘要，前端应展示「暂无分时数据」。
- `data_source` 当前恒为 `real`：模拟曲线分支已删除（2026-10-26）。

## 4. 详细信息

**方法 / 路径：** `GET /api/market/detail/{fund_code}`（公开）
**方法 / 路径：** `GET /api/market/detail/name/{fund_name}`（公开）

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| nav_limit | int | 500 | 历史净值返回条数上限（1–5000）。默认约近 2 年交易日，够前端切「近1月/3月/6月/1年/2年」 |

```bash
curl -s "$API/api/market/detail/110020" | python3 -m json.tool
curl -s "$API/api/market/detail/name/易方达沪深300ETF联接A" | python3 -m json.tool
# 只要最近 1 个月（约 22 个交易日）
curl -s "$API/api/market/detail/110020?nav_limit=22" | python3 -m json.tool
```

**响应要点：** `code / full_name / short_name / fund_type / issue_date / establish_date /
net_asset_scale / share_scale / manager_company / custodian / fund_manager / dividend_history /
management_fee / custody_fee / subscription_fee / purchase_fee / redemption_fee /
benchmark / tracking_target / is_qdii / nav_history`。

- **不再返回 `realtime`**（2026-10-26 起无实时行情数据源）；最新净值取 `nav_history[-1]`。
- `nav_history`：按日期升序，每项 `date / nav（单位净值）/ accumulated_nav（累计净值）/ daily_growth（日增长率，百分数）`，全部读本地 `fund_nav`。
- `is_qdii`：`true / false / null`，`null` 表示未知（不猜）。

**错误语义：**

| 状态码 | 场景 | body |
|---|---|---|
| 404 | 目录外代码（场内 ETF / 非白名单基金） | `{"detail": "基金 512890 不在支持目录内"}` |
| 404 | 名称解析不到目录内基金 | `{"detail": "无法识别基金名称: xxx"}` |
| 503 | 历史净值暂时不可用（未补齐且补数失败） | `{"detail": "基金 x 的历史净值不可用: ..."}` |

> 503 不是 404：基金本身在目录内、数据只是暂时没到。前端应展示「稍后再试」，而不是「该基金不存在」。

## 5. 搜索

**方法 / 路径：** `GET /api/market/search?keyword=...`（公开）

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| keyword | string | 必填 | 基金代码或名称片段 |
| top_n | int | 10 | 1–50 |

```bash
# 中文关键词需用 --data-urlencode 编码（HTTPS 下原始中文 query 会被拒）
curl -s --get "$API/api/market/search" \
  --data-urlencode "keyword=沪深300" \
  --data-urlencode "top_n=10" | python3 -m json.tool
```

**响应要点：** `{"total": n, "items": [...]}`，每项 `code / name / nav / nav_date / fund_type / net_asset_scale`。

- 只搜支持目录（`fund_catalog`）：**搜场内 ETF 代码（如 `512890`）返回 `{"total": 0, "items": []}`**；
  搜名称会命中名称相关的场外基金（如搜「沪深300」返回沪深300 联接/指数基金）。
- 不再返回实时行情字段（`price` / `change_pct` / `change` 已删除），改由 `nav` / `nav_date` 展示最新净值。
