# 08-行情数据

**被测模块**：`server/services/finance_api_service.py`
**测试文件**：`tests/unit/server/services/test_finance_api_service.py`
**测试方法**：纯函数直测；读缓存的方法给类级 `_spot_dict` 种入样本；akshare 依赖方法用 `sys.modules` 注入假 akshare 返回「录制样本 DataFrame」；全程离线、不联网。

## 功能

行情数据的事实查询与格式化：纯函数做名称匹配/字段清洗，`_spot_dict` 缓存支撑 O(1) 行情/榜单/资金流/搜索/分类查询，akshare 提供 K 线、分时、净值、刷新等外部数据源。

## 测试说明（无源码改动）

- 本模块**未改任何源码**：`__init__` 为空、`_spot_dict`/`_fund_list_cache` 为类级缓存可直接种入，akshare 为方法内 `import` 可用 `sys.modules` 注入假模块。
- **「录制样本 DataFrame」**：按 akshare 的真实列名（`代码`/`名称`/`最新价`/`涨跌幅`…、K线 `日期`/`开盘`/`收盘`…、净值 `净值日期`/`单位净值`…）构造样本 DataFrame，替代真实 akshare 网络返回，实现离线确定性测试。
- **可复现性**：`_generate_intraday_fallback` 用 `md5(fund_code)` 作随机种子，模拟分时走势结果可复现，测试据此断言固定输出。
- 未发现需要修复的功能缺陷。
