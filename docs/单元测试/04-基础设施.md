## 功能

基础设施层的零散工具：SSE 事件格式化与流式响应构建、全局配置读取、行情缓存调度器的交易时段判断。

## 业务场景 / 预期结果 / 测试结果

### 一、`format_sse_event` —— SSE 事件格式化（3 例）

**业务场景**：把事件类型与数据拼成 `data: <json>\n\n` 的 SSE 帧，中文不得被转义成 `\uXXXX`（否则前端乱码）。

| 场景 | 预期 |
|------|------|
| 正常格式 | `data: {"type": "message", "content": "hi"}\n\n` |
| 中文 | 原样保留「你好」，不出现 `你` |
| 事件类型 | 写入 data 内的 `type` 字段 |

**测试结果**：3 例全部通过。

### 二、`create_sse_stream_response` —— 流式响应构建（1 例）

**业务场景**：构建标准 SSE 响应，`media_type` 与三个响应头固定。

| 场景 | 预期 |
|------|------|
| 构建响应 | `media_type="text/event-stream"`，`X-Session-ID`=入参，`Cache-Control=no-cache`，`Connection=keep-alive` |

**测试结果**：1 例通过。

### 三、`Settings` —— 配置读取与默认值（3 例）

**业务场景**：从环境变量读配置，未设置时回退默认值；非法日志级别回退 DEBUG。

| 场景 | 预期 |
|------|------|
| 未设置 | `LOG_LEVEL=DEBUG`、`DB_PATH=server_data.db`、`EMBED_DIM=768`、`LYRA_MAX_TOKENS=4096`、`EMOTION_DETECTION_ENABLED=True` 等 |
| 已设置 | 读取环境变量（`WARNING` / `/tmp/etf-test.db` / `512` / `2048` / `false`） |
| 非法日志级别 | 回退 `DEBUG` |

**测试结果**：3 例全部通过。

### 四、`_is_trading_time` —— 交易时段判断（7 例）

**业务场景**：A 股交易时段 = 工作日 9:30–15:00（北京时间）。边界：9:30 含、15:00 不含。

| 场景 | 预期 |
|------|------|
| 工作日盘中（周一 10:00） | `True` |
| 恰好 9:30（开盘） | `True` |
| 9:29（开盘前） | `False` |
| 14:59（收盘前） | `True` |
| 恰好 15:00（收盘） | `False` |
| 周六 | `False` |
| 周日 | `False` |

**测试结果**：7 例全部通过。

  --cov=server.services.spot_cache_scheduler --cov-report=term-missing
