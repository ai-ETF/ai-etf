# 06-组合交易

**被测模块**：`server/services/portfolio_service.py`
**测试文件**：`tests/unit/server/services/test_portfolio_service.py`
**测试方法**：替换 `svc._client` 为内存多表 `FakeClient`（支持 `select/insert/update/delete/eq/lte/order/limit/range/count`），akshare/urllib 用 `sys.modules` 注入替身，外部服务（FundFeeService/RiskService/FinanceApiService）用 monkeypatch 替身，时间用 monkeypatch 冻结；全程不联网、不连 Supabase。

## 功能

场外基金持仓交易核心：按金额申购（外扣法）、按份额赎回、15:00 截止与 T+N 确认、加权平均成本价、货基每日收益入账、每日资产快照。**资金计算正确性的核心模块**。

## 运行方式

```bash
poetry run pytest tests/unit/server/services/test_portfolio_service.py -v
# 含覆盖率
poetry run pytest tests/unit/server/services/test_portfolio_service.py \
  --cov=server.services.portfolio_service --cov-report=term-missing
```

> 本次 76 例全部通过。覆盖率：`portfolio_service.py` 664 条语句、136 条未覆盖（**80%**）。
> 未覆盖主要三类：
> 1. **被冻结的时间函数** `_beijing_now`/`_now_iso`/`_beijing_date`（测试用 monkeypatch 冻结，原函数体不执行）；
> 2. **大量 `except Exception` 防御分支**（各方法的兜底返回）；
> 3. **fallback 分支**（净值回退订单价、费率回退、订单写入失败回滚等）。

## 测试说明（无源码改动）

- 本模块**未改任何源码**即完成测试：`__init__` 只设 `self._client = None`，`client` 属性惰性加载，可注入 `FakeClient`；akshare/urllib/外部服务均为方法内 `import`，用 monkeypatch 替身。
- 需为 C 类搭建了三样测试基建：**多表 FakeClient**（五张表 + `update/delete/lte/range/count`）、**akshare 替身**（`sys.modules` 注入，避免真实联网/重导入）、**时间冻结**。
- 未发现需要修复的资金安全缺陷（B 类已修复的「费率缺失拒绝」口径在 `_confirm_one_order` 卖出分支有专门用例覆盖）。
