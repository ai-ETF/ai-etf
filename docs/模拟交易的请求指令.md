## 环境配置

```bash
# 本地开发

# 远程服务器

BASE="$HOST/api/portfolio"
```

## 获取 JWT Token

```bash
# 登录获取 access_token
TOKEN=$(curl -s -X POST "$HOST/api/secure-chat/login" \
  -H "Content-Type: application/json" \
  -d '{"email":"lpqst@outlook.com","password":"ai-ETF"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['access_token'])")

AUTH="Authorization: Bearer $TOKEN"
echo "Token: ${TOKEN:0:20}..."
```

## 一、账户与持仓查询

### 1.1 查看账户概况

```bash
curl -s -H "$AUTH" "$BASE/account" | python3 -m json.tool
```

返回字段：`cash`(可用现金)、`frozen_cash`(冻结资金)、`position_value`(持仓市值)、`total_assets`(总资产)、`total_pnl`(总盈亏)、`total_return_rate`(总收益率)

### 1.2 查看持仓列表

```bash
curl -s -H "$AUTH" "$BASE/positions?include_quote=true" | python3 -m json.tool
```

### 1.3 查看交易流水

```bash
# 全部流水
curl -s -H "$AUTH" "$BASE/trade-flow?page=1&page_size=20" | python3 -m json.tool

# 按基金筛选
curl -s -H "$AUTH" "$BASE/trade-flow?fund_code=110020&page=1&page_size=10" | python3 -m json.tool

# 按方向筛选（buy/sell）
curl -s -H "$AUTH" "$BASE/trade-flow?direction=buy&page=1&page_size=10" | python3 -m json.tool
```

### 1.4 查看每日收益率

```bash
curl -s -H "$AUTH" "$BASE/daily-returns?days=7" | python3 -m json.tool
```

## 四、拦截与边界验证

### 4.1 ETF 申购拦截（场内ETF不走场外）

```bash
curl -s -X POST "$BASE/apply-purchase" \
  -H "Content-Type: application/json" \
  -H "$AUTH" \
  -d '{"fund_code":"510300","amount":1000}' | python3 -m json.tool
# 预期：场外 ETF 暂不支持交易，请使用场外开放式基金
```

### 4.2 白名单拦截

```bash
curl -s -X POST "$BASE/apply-purchase" \
  -H "Content-Type: application/json" \
  -H "$AUTH" \
  -d '{"fund_code":"000001","amount":1000}' | python3 -m json.tool
# 预期：暂不支持基金 000001 的交易
```

### 4.3 赎回拦截 — 未持有基金

```bash
curl -s -X POST "$BASE/apply-redeem" \
  -H "Content-Type: application/json" \
  -H "$AUTH" \
  -d '{"fund_code":"009067","quantity":10}' | python3 -m json.tool
# 预期：未持有基金 009067，无法赎回
```

### 4.4 赎回拦截 — pending 申购未确认

```bash
# 先申购 110020 → 产生 pending 订单
curl -s -X POST "$BASE/apply-purchase" \
  -H "Content-Type: application/json" \
  -H "$AUTH" \
  -d '{"fund_code":"110020","amount":1000}' > /dev/null

# 此时尝试赎回同基金 → 被拦截
curl -s -X POST "$BASE/apply-redeem" \
  -H "Content-Type: application/json" \
  -H "$AUTH" \
  -d '{"fund_code":"110020","quantity":10}' | python3 -m json.tool
# 预期：存在待确认的申购订单，份额确认前无法赎回
```

### 4.5 最低申购金额校验

```bash
curl -s -X POST "$BASE/apply-purchase" \
  -H "Content-Type: application/json" \
  -H "$AUTH" \
  -d '{"fund_code":"110020","amount":5}' | python3 -m json.tool
```

## 常见问题

**Q: 申购显示"无法获取净值"？**
A: akshare 没有该基金的净值数据。可以用 `"price"` 参数手动指定净值。

**Q: 赎回被拦截"存在待确认的申购订单"？**
A: pending 订单确认前无法赎回同基金。先调 `/confirm-pending` 确认。

**Q: 交易流水为空？**
A: 只有已确认的订单才写入 trade_flow 表，pending 订单确认后才有记录。

**Q: 非交易时间申购？**
A: 系统自动识别，显示"下一交易日受理"。资金冻结，等确认日才扣款建仓。
