# 文档目录

本目录按「文档用途」组织，不按业务功能。新增文档前先按下面的表选目录，不要新建顶层目录。

## 该放哪

| 这篇文档用来做什么 | 放到 |
|---|---|
| 说明要做什么、验收标准 | `10-需求/` |
| 说明系统怎么做、目标形态 | `20-设计/`（按业务域分子目录） |
| 对外 API 契约、接口测试指令 | `30-接口/` |
| 部署、迁移、故障处理、日常操作 | `40-运维/` |
| 测试规划、用例、测试命令 | `50-测试/` |
| 当前事实、外部契约、对接说明 | `60-参考/` |
| 选型理由、事故根因、修复方案 | `70-方案与决策/` |
| 已失效或被替代 | `90-归档/` |

判断标准是「读者拿它来做什么」，不是「它写了什么内容」。

## 顶层目录

| 目录 | 内容 |
|---|---|
| `00-协作规范/` | 协作方式、工具配置 |
| `10-需求/` | 需求与验收标准 |
| `20-设计/` | 系统设计，按业务域分：行情、账户与认证、基金与交易、风控、数据库、用户画像 |
| `30-接口/` | 对外 API 契约、curl 指令、一致性校验脚本 |
| `40-运维/` | 部署、数据库迁移、白名单同步、故障处理 |
| `50-测试/` | 单元测试、集成测试、API 测试命令 |
| `60-参考/` | 当前取数现状、对外数据源契约、前端对接 |
| `70-方案与决策/` | 选型理由、事故根因、修复方案 |
| `90-归档/` | 已失效或被替代的文档，按年份归档 |

命名、frontmatter、归档和校验规则见 [ai-collaboration 技能](../.claude/skills/ai-collaboration/SKILL.md)（规则 2）。

查找方式：按目录和文件名浏览；或在 `docs/` 下执行 `rg 'tags: 行情' -l`（按标签）、`rg '关键词'`（全文）。
