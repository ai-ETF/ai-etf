# 服务端 API 测试指南

> 测试前请确保服务已启动：`uvicorn server.app:app --host 0.0.0.0 --port 8000`

**服务器地址：** `http://47.113.220.182:8000`

---

## ⚠️ 注意事项

- **所有对话接口（除登录外）都需要 JWT 认证**
- 先调用登录接口获取 `access_token`，然后在后续请求的 Header 中携带：`Authorization: Bearer <token>`
- `user_id` 从 JWT token 中自动读取，无需在请求体中传入

---

## 1. 登录接口

```bash
# 登录获取 JWT token
curl -X POST "http://47.113.220.182:8000/api/secure-chat/login" \
  -H "Content-Type: application/json" \
  -d '{"email": "lpqst@outlook.com", "password": "ai-ETF"}'
```

**返回示例：**

```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "token_type": "bearer",
  "user_id": "uuid-string",
  "expires_in": 3600
}
```

---

## 2. 发送消息（需认证）

```bash
# 发送消息并获取流式回答（SSE）
curl -X POST "http://47.113.220.182:8000/api/secure-chat" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
  -d '{"question": "你好，请问 ETF 是什么？"}'
```

**参数说明：**
| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| question | string | ✅ | 用户问题 |
| chat_id | string | ❌ | 会话 ID，不传则自动创建新会话 |

**SSE 事件类型：**
- `token` - LLM 生成的 token
- `done` - 生成结束，包含 chat_id
- `error` - 错误信息

## 4. 会话管理接口（需认证）

### 4.1 获取会话列表

```bash
curl -X GET "http://47.113.220.182:8000/api/secure-chat/chats?limit=50" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..."
```

**返回示例：**
```json
{
  "total": 2,
  "chats": [
    {
      "id": "chat-uuid",
      "user_id": "user-uuid",
      "title": "你好，请问 ETF 是什么...",
      "created_at": "2025-01-01T00:00:00Z",
      "updated_at": "2025-01-01T00:01:00Z"
    }
  ]
}
```

### 4.2 获取会话消息历史

```bash
curl -X GET "http://47.113.220.182:8000/api/secure-chat/chats/{chat_id}/messages?limit=100" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..."
```

**返回示例：**
```json
{
  "chat_id": "chat-uuid",
  "chat_title": "你好，请问 ETF 是什么...",
  "total": 4,
  "messages": [
    {
      "id": "msg-uuid",
      "chat_id": "chat-uuid",
      "role": "user",
      "content": "你好，请问 ETF 是什么？",
      "created_at": "2025-01-01T00:00:00Z"
    },
    {
      "id": "msg-uuid",
      "chat_id": "chat-uuid",
      "role": "assistant",
      "content": "ETF是...",
      "created_at": "2025-01-01T00:00:05Z"
    }
  ]
}
```

### 4.3 删除会话

```bash
curl -X DELETE "http://47.113.220.182:8000/api/secure-chat/chats/{chat_id}" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..."
```

**返回示例：**
```json
{
  "message": "会话已删除",
  "chat_id": "chat-uuid"
}
```

## 5. 完整测试流程示例

```bash
# 1. 登录
curl -X POST "http://47.113.220.182:8000/api/secure-chat/login" \
  -H "Content-Type: application/json" \
  -d '{"email": "test@example.com", "password": "your_password"}'

# 假设返回 token: eyJhbGciOiJIUzI1NiIs...

# 2. 发送第一条消息（创建新会话）
curl -X POST "http://47.113.220.182:8000/api/secure-chat" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
  -d '{"question": "你好，请问 ETF 是什么？"}'

# 假设返回 chat_id: abc123

# 3. 在同一会话中继续对话（带历史上下文）
curl -X POST "http://47.113.220.182:8000/api/secure-chat" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
  -d '{"question": "能详细解释一下吗？", "chat_id": "abc123"}'

# 4. 查看会话列表
curl -X GET "http://47.113.220.182:8000/api/secure-chat/chats" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..."

# 5. 查看会话消息历史
curl -X GET "http://47.113.220.182:8000/api/secure-chat/chats/abc123/messages" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..."

# 6. 删除会话
curl -X DELETE "http://47.113.220.182:8000/api/secure-chat/chats/abc123" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..."
```

## 6. 认证失败测试

```bash

  -H "Content-Type: application/json" \
  -d '{"question": "你好"}'

# 错误 token → 401

  -H "Content-Type: application/json" \
  -H "Authorization: Bearer invalid_token" \
  -d '{"question": "你好"}'
```

## 7. 无认证版本（测试用）

如果需要测试无认证版本，可以使用 `/api/messages` 接口，user_id 需要在请求体中传入：

```bash
# 发送消息（无认证，user_id 从请求体传入）
curl -X POST "http://47.113.220.182:8000/api/messages" \
  -H "Content-Type: application/json" \
  -d '{"user_id": "test-user-id", "question": "你好"}'
```

## 接口总览

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| POST | `/api/secure-chat/login` | 登录获取 JWT | ❌ |
| POST | `/api/secure-chat` | 发送消息（流式） | ✅ JWT |
| GET | `/api/secure-chat/chats` | 会话列表 | ✅ JWT |
| GET | `/api/secure-chat/chats/{id}/messages` | 消息历史 | ✅ JWT |
| DELETE | `/api/secure-chat/chats/{id}` | 删除会话 | ✅ JWT |
| POST | `/api/messages` | 发送消息（无认证版） | ❌ |
