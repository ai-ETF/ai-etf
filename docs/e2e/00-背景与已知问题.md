### 2. 接口规模与鉴权分级（2026-09-20 逐个核对）

**共 57 个端点**（56 个唯一路径；`/api/portfolio/auto-invest/config` 是 GET+POST 共用一条路径）。

| 鉴权类型 | 数量 | 说明 |
|---|---|---|
| 🔒 JWT 必需 | **23** | `Authorization: Bearer <token>`，Supabase JWT（HS256），`user_id` 从 token 读，**不要在请求体传** |
| — 公开 | **27** | 行情、健康检查、登录/注册、上传（见下） |
| `X-User-Id` 开发接口 | **7** | `/api/portfolio/test/*`，免 JWT，用 `X-User-Id` header 指定用户；**仅非生产环境可用**（生产返回 404） |

> 💡 对 E2E 有用：`/api/portfolio/test/*` 这 7 个接口可以**绕过登录流程**直接构造持仓/交易数据，适合做测试前置准备。但生产环境不可用，且它测的是「数据准备」不是「真实用户路径」，真实验证仍需走 JWT 路径。

### 技术难点（E2E 要专门处理）

- **SSE 流式对话**：首页发消息是 `text/event-stream`，小程序端用 `uni.request` + `enableChunked` 分块接收（`pages/index/index.vue`）。自动化工具对 SSE 的捕获是已知痛点，断言方式要专门设计。
- **行情接口放行未登录**：`request.ts` 里 `/api/market/` 被特判为公开请求，未登录也放行。测试登录态时要留意这个例外。
- **登录态是 1 小时本地会话**：token 过期由前端 `expireAuthAndRedirect` 处理，E2E 要覆盖过期/401 场景（即 P4）。

## 六、仓库约定（必须遵守）

### 后端 `ai-etf`

- 用 **poetry** 管依赖，**禁用 pip**，不直接改环境文件
- **不在 `dev` 分支直接开发**，必须建新分支
- **禁止读取 `.env`** 内容
- 改 `.gitignore` **只能追加**
- 启动需 Supabase 连接（`server/app.py` 的 lifespan 会强校验，连不上直接启动失败）；启动时还会起行情缓存调度器

### 前端 `application`

- 用 `uni.xxx` API，**不用 Web API**（禁 `fetch`/`localStorage`）
- 路由在 `src/pages.json` 声明，不用 vue-router
- 用 uni-app 基础组件（`<view>`/`<text>`），不用 HTML 标签
- 颜色用 SCSS 变量（自动注入，勿手写 import）；红涨绿跌（涨 `#DC2626`、跌 `#16A34A`）
- 图标必须 SVG，禁 emoji
