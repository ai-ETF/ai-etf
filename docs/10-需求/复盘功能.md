# 复盘功能

## 1. 背景与目标

账户页需要一条可复核的资产曲线：用户能看到每个交易日的账户总资产，以及相邻交易日之间的
收益变化。当前快照依赖手动触发、日期不区分交易日、估值取最新净值，无法支撑可信的复盘。

## 2. 需求

1. 以 A 股交易日为单位，对每个用户账户做统一估值。
2. 每个交易日生成一条账户历史快照，包含总资产及现金、冻结、在途赎回款、持仓市值分项。
3. 只有「有效快照」参与收益计算；缺净值、非交易日、系统读取失败等情况不得伪装成有效数据。
4. 基于相邻交易日的有效快照计算每日收益；跨多日时返回区间收益与交易日数，不伪造单日收益。
5. 快照生成幂等：同一用户同一交易日只有一条记录，已有效快照不被重复任务覆盖。

## 3. 验收标准

- 交易日 T 的快照使用 T 日净值，不使用 T-1 或更早净值冒充。
- 任一非货基持仓缺 T 日净值时，该用户 T 日快照为 `invalid`，不进入 `/daily-returns`。
- 周末、节假日不生成快照；T 日快照在 T+1 08:45 生成。
- `/daily-returns` 的 `daily_return` 只在相邻交易日均有有效快照时有值；缺口日为 `null`，
  同时给出 `period_days` 与 `period_return`。
- 快照分项满足 `total_assets = cash + frozen_cash + settling_cash + position_value`。
