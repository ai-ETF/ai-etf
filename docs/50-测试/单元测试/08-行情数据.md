# 08-行情数据

**被测模块**：`server/services/finance_api_service.py`
**测试文件**：`tests/unit/server/services/test_finance_api_service.py`
**测试方法**：纯函数直测；净值/元数据用内存 Fake（`FakeFundNav` / `FakeFundMeta`）注入；K 线 / 分时用 `sys.modules` 注入假 akshare；全程离线、不联网、不连 Supabase。

> **2026-10-26 变更**：场内 30 秒行情缓存（`_spot_dict`）与由它派生的行情 / 榜单 / 资金流 /
> 搜索 / 筛选 / 分类方法全部删除，其测试用例随之删除；新增「目录内读 DB、目录外抛
> `FundNotSupported`」的契约用例与 `search_catalog` 用例。原 40 例 → 现 37 例。

## 功能

场外基金事实数据查询：纯函数做名称匹配 / 字段清洗；净值走 `FundNavService`（DB），
名称解析与搜索走 `FundMetaService`（`fund_catalog` 视图）；K 线与分时仍直连 akshare / 新浪。

## 测试说明

- 不做真实网络 / 真实 DB：净值与元数据由 `FakeFundNav` / `FakeFundMeta` 提供，
  K 线与分时由 `sys.modules` 注入的假 akshare 提供。
- **目录边界是契约用例**：目录外代码必须抛 `FundNotSupported`（API 层转 404），
  不允许回退上游。这条约束由三条用例分别守住 `query_detail` / `_query_nav` / `_query_nav_history`。
- 分时「取不到当日数据」返回空列表而非伪造曲线 —— 原 `_generate_intraday_fallback`
  （用 `md5(fund_code)` 生成 240 点随机走势）已删除，对应断言同步改为空列表。
