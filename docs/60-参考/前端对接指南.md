# 基金查询前端对接指南

本文档提供前端对接基金查询 API 的完整示例，包括 K 线图、分时图、净值卡片与搜索。

> **2026-10-26 变更（必读）**：产品只做场外基金交易，**没有实时行情**。
> `/spot/*`、`/ranking`、`/money-flow/*`、`/filter`、`/categories`、`/category/{cat}`
> 全部下线；`/detail` 不再返回 `realtime`。价格展示一律用**最新净值**（`nav` / `nav_date`），
> 搜索与详情只认支持目录内的场外基金（场内 ETF 代码 404 / 搜不到）。
> 因此文中的「5 秒轮询」策略已废弃，净值每日公布一次，按次加载即可。

## API接口列表

### 基础URL
```
http://localhost:8000/api/market
```

### 接口详情

| 接口 | 方法 | 说明 |
|------|------|------|
| `/kline/{code}` | GET | K线数据（按代码） |
| `/kline/name/{name}` | GET | K线数据（按名称） |
| `/intraday/{code}` | GET | 当日分时（按代码；无数据时 `items: []`） |
| `/detail/{code}` | GET | 基金详情（费率/规模/历史净值） |
| `/detail/name/{name}` | GET | 基金详情（按名称） |
| `/search?keyword=` | GET | 搜索（只命中目录内场外基金） |

> 完整字段与错误语义见 `docs/30-接口/03-行情.md`。

### K线接口参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `period` | string | daily | K线周期：daily/weekly/monthly |
| `start_date` | string | - | 起始日期（2024-01-01） |
| `end_date` | string | - | 结束日期（2024-12-31） |
| `limit` | int | - | 返回数据条数（1-1000） |

## React + ECharts K线图示例

### 安装依赖

```bash
npm install echarts echarts-for-react

```

### K线图组件

```tsx
// components/KlineChart.tsx
import React, { useEffect, useState } from 'react';
import ReactECharts from 'echarts-for-react';
import axios from 'axios';

interface KlineData {
  date: string;
  open: number;
  close: number;
  high: number;
  low: number;
  volume: number;
  change_pct: number;
}

interface KlineChartProps {
  fundCode: string;
  period?: 'daily' | 'weekly' | 'monthly';
  limit?: number;
}

const KlineChart: React.FC<KlineChartProps> = ({
  fundCode,
  period = 'daily',
  limit = 60
}) => {
  const [data, setData] = useState<KlineData[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetchKlineData();
  }, [fundCode, period, limit]);

  const fetchKlineData = async () => {
    try {
      setLoading(true);
      const response = await axios.get(
        `http://localhost:8000/api/market/kline/${fundCode}`,
        { params: { period, limit } }
      );
      setData(response.data.items);
    } catch (error) {
      console.error('获取K线数据失败:', error);
    } finally {
      setLoading(false);
    }
  };

  const getOption = () => {
    const dates = data.map(item => item.date);
    const klineData = data.map(item => [item.open, item.close, item.low, item.high]);
    const volumes = data.map(item => item.volume);

    return {
      title: {
        text: `${fundCode} K线图`,
        left: 'center'
      },
      tooltip: {
        trigger: 'axis',
        axisPointer: { type: 'cross' },
        formatter: function (params: any) {
          const data = params[0].data;
          return `
            日期: ${params[0].name}<br/>
            开盘: ${data[0]}<br/>
            收盘: ${data[1]}<br/>
            最低: ${data[2]}<br/>
            最高: ${data[3]}
          `;
        }
      },
      legend: {
        data: ['K线', '成交量'],
        bottom: 10
      },
      grid: [
        { left: '10%', right: '8%', top: '10%', height: '50%' },
        { left: '10%', right: '8%', top: '70%', height: '20%' }
      ],
      xAxis: [
        {
          type: 'category',
          data: dates,
          gridIndex: 0
        },
        {
          type: 'category',
          data: dates,
          gridIndex: 1
        }
      ],
      yAxis: [
        {
          scale: true,
          gridIndex: 0,
          splitLine: { show: true }
        },
        {
          scale: true,
          gridIndex: 1,
          splitLine: { show: false }
        }
      ],
      dataZoom: [
        {
          type: 'inside',
          xAxisIndex: [0, 1],
          start: 50,
          end: 100
        },
        {
          show: true,
          xAxisIndex: [0, 1],
          type: 'slider',
          bottom: 10,
          start: 50,
          end: 100
        }
      ],
      series: [
        {
          name: 'K线',
          type: 'candlestick',
          data: klineData,
          xAxisIndex: 0,
          yAxisIndex: 0,
          itemStyle: {
            color: '#ef232a',
            color0: '#14b143',
            borderColor: '#ef232a',
            borderColor0: '#14b143'
          }
        },
        {
          name: '成交量',
          type: 'bar',
          data: volumes,
          xAxisIndex: 1,
          yAxisIndex: 1,
          itemStyle: {
            color: function (params: any) {
              const idx = params.dataIndex;
              return data[idx].close >= data[idx].open ? '#ef232a' : '#14b143';
            }
          }
        }
      ]
    };
  };

  if (loading) {
    return <div className="loading">加载中...</div>;
  }

  return (
    <div className="kline-chart">
      <ReactECharts
        option={getOption()}
        style={{ height: '500px', width: '100%' }}
        notMerge={true}
        lazyUpdate={true}
      />
    </div>
  );
};

export default KlineChart;
```

### 安装依赖

npm install lightweight-charts

### K线图组件

```tsx
// components/LightweightKline.tsx
import React, { useEffect, useRef, useState } from 'react';
import { createChart, IChartApi, CandlestickData } from 'lightweight-charts';
import axios from 'axios';

interface KlineData {
  date: string;
  open: number;
  close: number;
  high: number;
  low: number;
  volume: number;
}

interface LightweightKlineProps {
  fundCode: string;
  period?: 'daily' | 'weekly' | 'monthly';
  limit?: number;
}

const LightweightKline: React.FC<LightweightKlineProps> = ({
  fundCode,
  period = 'daily',
  limit = 100
}) => {
  const chartRef = useRef<HTMLDivElement>(null);
  const chartInstance = useRef<IChartApi | null>(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetchKlineData();

    return () => {
      if (chartInstance.current) {
        chartInstance.current.remove();
      }
    };
  }, [fundCode, period, limit]);

  const fetchKlineData = async () => {
    try {
      setLoading(true);
      const response = await axios.get(
        `http://localhost:8000/api/market/kline/${fundCode}`,
        { params: { period, limit } }
      );

      const klineData: CandlestickData[] = response.data.items.map((item: KlineData) => ({
        time: item.date,
        open: item.open,
        high: item.high,
        low: item.low,
        close: item.close,
      }));

      renderChart(klineData);
    } catch (error) {
      console.error('获取K线数据失败:', error);
    } finally {
      setLoading(false);
    }
  };

  const renderChart = (data: CandlestickData[]) => {
    if (!chartRef.current) return;

    // 清除旧图表
    if (chartInstance.current) {
      chartInstance.current.remove();
    }

    // 创建新图表
    const chart = createChart(chartRef.current, {
      width: chartRef.current.clientWidth,
      height: 500,
      layout: {
        background: { color: '#ffffff' },
        textColor: '#333',
      },
      grid: {
        vertLines: { color: '#e1e1e1' },
        horzLines: { color: '#e1e1e1' },
      },
      crosshair: {
        mode: 1,
      },
      rightPriceScale: {
        borderColor: '#cccccc',
      },
      timeScale: {
        borderColor: '#cccccc',
        timeVisible: true,
        secondsVisible: false,
      },
    });

    const candlestickSeries = chart.addCandlestickSeries({
      upColor: '#ef232a',
      downColor: '#14b143',
      borderUpColor: '#ef232a',
      borderDownColor: '#14b143',
      wickUpColor: '#ef232a',
      wickDownColor: '#14b143',
    });

    candlestickSeries.setData(data);

    chartInstance.current = chart;

    // 响应式调整
    const handleResize = () => {
      if (chartRef.current && chartInstance.current) {
        chartInstance.current.applyOptions({ width: chartRef.current.clientWidth });
      }
    };
    window.addEventListener('resize', handleResize);
  };

  if (loading) {
    return <div className="loading">加载中...</div>;
  }

  return <div ref={chartRef} className="lightweight-kline" />;
};

export default LightweightKline;
```

## 净值卡片组件

> 替代原「实时行情组件」：数据来自 `/detail` 的 `nav_history`，不再有价格/成交量/盘口。

```tsx
// components/NavCard.tsx
import React, { useEffect, useState } from 'react';
import axios from 'axios';

interface NavPoint {
  date: string;
  nav: number | null;
  accumulated_nav: number | null;
  daily_growth: number | null;
}

interface FundDetail {
  code: string;
  full_name?: string;
  net_asset_scale?: string;
  is_qdii?: boolean | null;
  nav_history?: NavPoint[];
}

const NavCard: React.FC<{ fundCode: string }> = ({ fundCode }) => {
  const [detail, setDetail] = useState<FundDetail | null>(null);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    if (!fundCode) return;
    axios
      .get(`http://localhost:8000/api/market/detail/${fundCode}`, {
        params: { nav_limit: 2 },
      })
      .then((res) => setDetail(res.data))
      .catch((err) => {
        // 404：基金不在支持目录内（场内 ETF 等），不要重试、不要回退展示
        setError(err.response?.data?.detail ?? '加载失败');
      });
  }, [fundCode]);

  if (error) return <div className="nav-card error">{error}</div>;
  if (!detail) return <div className="nav-card">加载中…</div>;

  const latest = detail.nav_history?.[detail.nav_history.length - 1];
  const growth = latest?.daily_growth;
  const isUp = (growth ?? 0) >= 0;

  return (
    <div className="nav-card">
      <div className="fund-title">
        {detail.full_name}（{detail.code}）
        {detail.is_qdii && <span className="badge">QDII</span>}
      </div>
      <div className="nav-value">
        {latest?.nav?.toFixed(4) ?? '—'}
        <span className={isUp ? 'up' : 'down'}>
          {growth == null ? '' : `${isUp ? '+' : ''}${growth.toFixed(2)}%`}
        </span>
      </div>
      <div className="nav-date">净值日期：{latest?.date ?? '—'}</div>
      <div className="nav-note">
        场外基金每日公布一次净值，页面刷新即取最新；无需定时轮询。
      </div>
    </div>
  );
};

export default NavCard;
```

**错误处理要点**

| 状态码 | 含义 | 前端表现 |
|---|---|---|
| 404 | 目录外代码 / 名称无法识别 | 显示后端 `detail` 文案（如「基金 512890 不在支持目录内」），不重试 |
| 503 | 历史净值暂时不可用 | 显示「稍后再试」，保留页面框架 |

## 搜索框组件

> 搜索只返回**支持目录内的场外基金**。搜场内 ETF 代码（如 `512890`）返回 `total: 0`，
> 前端应展示「没有找到相关基金」，不要再去调详情接口试。

```tsx
// components/FundSearch.tsx
import React, { useState } from 'react';
import axios from 'axios';

interface SearchItem {
  code: string;
  name: string;
  nav: number | null;
  nav_date: string | null;
  fund_type: string | null;
  net_asset_scale: string | null;
}

const FundSearch: React.FC<{ onPick: (code: string) => void }> = ({ onPick }) => {
  const [keyword, setKeyword] = useState('');
  const [items, setItems] = useState<SearchItem[]>([]);
  const [searched, setSearched] = useState(false);

  const doSearch = async () => {
    const q = keyword.trim();
    if (!q) return;
    // 中文关键词交给 axios 编码，不要手工拼 URL
    const { data } = await axios.get('http://localhost:8000/api/market/search', {
      params: { keyword: q, top_n: 10 },
    });
    setItems(data.items ?? []);
    setSearched(true);
  };

  return (
    <div className="fund-search">
      <input
        value={keyword}
        onChange={(e) => setKeyword(e.target.value)}
        onKeyDown={(e) => e.key === 'Enter' && doSearch()}
        placeholder="输入基金名称或代码，如 沪深300 / 110020"
      />
      <button onClick={doSearch}>搜索</button>

      {searched && items.length === 0 && <div className="empty">没有找到相关基金</div>}

      <ul>
        {items.map((it) => (
          <li key={it.code} onClick={() => onPick(it.code)}>
            <span className="name">{it.name}</span>
            <span className="code">{it.code}</span>
            <span className="nav">{it.nav == null ? '—' : it.nav.toFixed(4)}</span>
            <span className="nav-date">{it.nav_date ?? '—'}</span>
          </li>
        ))}
      </ul>
    </div>
  );
};

export default FundSearch;
```

## 使用建议

### 图表库选择

| 特性 | ECharts | Lightweight Charts |
|------|---------|-------------------|
| 文件大小 | ~1MB | ~50KB |
| 功能丰富度 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| 金融专业度 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 性能 | 良好 | 优秀 |
| 学习成本 | 中等 | 低 |

**推荐**：
- 追求轻量和金融专业性 → **Lightweight Charts**
- 需要丰富的图表类型和自定义 → **ECharts**

### 数据刷新策略

净值每日公布一次（通常交易日 18:00 后），**不需要秒级轮询**：

```typescript
// 进入页面/切换基金时加载一次即可；用户手动刷新时再取
useEffect(() => {
  fetchDetail(fundCode);
}, [fundCode]);
```

K 线/分时同理：分时只在交易时段有意义，且取不到当日数据会返回空列表，
前端展示「暂无分时数据」即可，不要用定时器把空请求打满。
