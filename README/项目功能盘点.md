## ✅ 一、已实现 & 已注册（可正常调用）

| 功能 | 路由 | 描述 |
|---|---|---|
| 根健康检查 | `GET /` | 验证服务启动 |
| 测试端点 | `GET /api/test/hello` | 快速连通性测试 |
| 文档上传 | `POST /api/upload` | 下载文档 → 类型分析 → 分块 → 向量化 → 存储 Supabase |
| Edge Function 文件处理 | `POST /api/upload/process-file-from-edge` | 远程文件处理管线 |
| 上传健康检查 | `GET /api/upload/health` | 文档服务健康检测 |
| JWT 登录 | `POST /api/secure-chat/login` | Supabase Auth 邮箱密码登录，返回 access_token |
| 流式对话（JWT） | `POST /api/secure-chat` | 带认证的 LLM 对话，SSE 流式返回，会话自动管理 |
| 会话列表（JWT） | `GET /api/secure-chat/chats` | 当前用户会话列表 |
| 会话消息（JWT） | `GET /api/secure-chat/chats/{id}/messages` | 某次会话的消息历史 |
| 删除会话（JWT） | `DELETE /api/secure-chat/chats/{id}` | 删除会话及所有消息 |
| 简单对话 | `POST /api/simple-chat` | 无认证、无历史记录的单轮 LLM 对话，SSE 流式返回 |
| 添加自选股（JWT） | `POST /api/watchlist/add` | 添加到 Supabase watchlist 表 |
| 移除自选股（JWT） | `DELETE /api/watchlist/remove` | 从 watchlist 移除 |
| 自选股列表（JWT） | `GET /api/watchlist/list?include_quote=true` | 查询自选股，可选带实时行情 |
| 清空自选股（JWT） | `DELETE /api/watchlist/clear` | 清空当前用户所有自选股 |
| 自选股健康检查 | `GET /api/watchlist/health` | 公开，无需认证 |
| 实时行情查询 | `GET /api/market/spot/{code}` | 单只 ETF 实时行情（O(1) 哈希表查询） |
| 按名称查行情 | `GET /api/market/spot/name/{name}` | 按名称模糊匹配查询实时行情 |
| 涨幅榜 / 跌幅榜 | `GET /api/market/ranking` | ETF 排行榜（可排序、可控制方向） |
| K 线数据 | `GET /api/market/kline/{code}` | 历史 K 线（带文件缓存，TTL 1 天） |
| 按名称查 K 线 | `GET /api/market/kline/name/{name}` | 按名称查 K 线 |
| ETF 详细信息 | `GET /api/market/detail/{code}` | 完整信息（实时行情 + 费率 + 规模 + 管理人 + 净值） |
| 按名称查详情 | `GET /api/market/detail/name/{name}` | 按名称查 ETF 详情 |
| 搜索 ETF | `GET /api/market/search?keyword=` | 名称/代码模糊搜索 |
| 筛选 ETF | `POST /api/market/filter` | 多条件筛选（费率、规模、涨跌幅等） |
| 分类列表 | `GET /api/market/categories` | 自动分类（红利/科技/宽基/医药等 20+ 类） |
| 分类下基金 | `GET /api/market/category/{cat}` | 指定分类的 ETF 列表 |
| 分时图 | `GET /api/market/intraday/{code}` | 当日分时走势（真实数据 + 模拟降级） |
| 按名称查分时图 | `GET /api/market/intraday/name/{name}` | 按名称查分时图 |
| 资金流向 | `GET /api/market/money-flow/{code}` | 主力净流入/外盘/内盘/委比 |
| 按名称查资金流向 | `GET /api/market/money-flow/name/{name}` | 按名称查资金流向 |
| 资金流向榜 | `GET /api/market/money-flow/ranking` | 净流入/净流出排行榜 |
| 市场数据健康检查 | `GET /api/market/health` | 公开，无需认证 |

> 共 **32 个端点** 已注册可正常调用（原 17 个基础端点 + 15 个市场数据端点）。

## 📈 七、模拟交易系统规划

> 目标：实现一个完整的 ETF 模拟交易系统，涵盖看盘 → 自选 → 下单 → 持仓 → 盈亏分析全流程。

### P0 — 必须实现

| 功能 | 说明 |
|---|---|
| **模拟持仓管理** | 买入记录：代码、买入价、数量、时间。卖出减少持仓。持仓列表含成本价、现价、盈亏额/率 |
| **模拟交易记录** | 每笔买入/卖出生成流水：时间、代码、方向（买/卖）、价格、数量、成交金额。支持分页查询 |
| **账户概况** | 初始虚拟资金（如 100 万）。总资产 = 现金 + 持仓市值。总盈亏 = 总资产 - 初始资金。日/总收益率 |

### P1 — 最好实现

| 功能 | 说明 |
|---|---|
| **下单接口** | 买入：输入代码 + 数量（或金额），按最新价成交。卖出：选择持仓 ETF + 数量（或全仓）。校验：卖出不超持仓、资金不够不能买 |
| **持仓盈亏明细** | 每只 ETF 的：持仓天数、累计盈亏、盈亏率。按盈亏额排序 |
| **交易仪表盘** | 总资产走势图（每日快照曲线）、仓位分布饼图、盈利/亏损 TOP 5 |

### P2 — 锦上添花

| 功能 | 说明 |
|---|---|
| **快速下单** | 从行情页直接点"买入"跳转下单，自动填入代码和最新价 |
| **条件单/价格提醒** | 设定目标价，触发时通知 |
| **模拟分红** | 持仓 ETF 分红时按持有份额自动增加现金 |
