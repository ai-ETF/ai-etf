# AI-ETF 项目功能盘点

> 更新日期：2026-07-27

## ✅ 一、已实现 & 已注册（可正常调用）

| 功能 | 路由 | 描述 |
|---|---|---|
| 根健康检查 | `GET /` | 验证服务启动 |
| 测试端点 | `GET /api/test/hello` | 快速连通性测试 |
| 文档上传 | `POST /api/upload` | 下载文档 → 类型分析 → 分块 → 向量化 → 存储 Supabase |
| Edge Function 文件处理 | `POST /api/upload/process-file-from-edge` | 远程文件处理管线 |
| 上传健康检查 | `GET /api/upload/health` | 文档服务健康检测 |
| JWT 登录 | `POST /api/secure-chat/login` | Supabase Auth 邮箱密码登录，返回 access_token |
| 流式对话（JWT） | `POST /api/secure-chat` | 带认证的 LLM 对话，SSE 流式返回，会话自动管理 |
| 会话列表（JWT） | `GET /api/secure-chat/chats` | 当前用户会话列表 |
| 会话消息（JWT） | `GET /api/secure-chat/chats/{id}/messages` | 某次会话的消息历史 |
| 删除会话（JWT） | `DELETE /api/secure-chat/chats/{id}` | 删除会话及所有消息 |
| 简单对话 | `POST /api/simple-chat` | 无认证、无历史记录的单轮 LLM 对话，SSE 流式返回 |
| 添加自选股（JWT） | `POST /api/watchlist/add` | 添加到 Supabase watchlist 表 |
| 移除自选股（JWT） | `DELETE /api/watchlist/remove` | 从 watchlist 移除 |
| 自选股列表（JWT） | `GET /api/watchlist/list?include_quote=true` | 查询自选股，可选带实时行情 |
| 清空自选股（JWT） | `DELETE /api/watchlist/clear` | 清空当前用户所有自选股 |
| 自选股健康检查 | `GET /api/watchlist/health` | 公开，无需认证 |

## 📊 五、完整架构概览

```
前端请求
  │
  ├─ FastAPI (app.py) ─── CORS 中间件
  │     │
  │     ├── /api/upload/*          ← 文档处理管线
  │     ├── /api/ask               ← RAG 问答（已弃用）
  │     ├── /api/test/hello        ← 测试
  │     ├── /api/secure-chat/*     ← JWT 认证聊天
  │     ├── /api/simple-chat       ← 简单对话
  │     ├── /api/watchlist/*       ← 自选股（JWT）
  │     │
  │     └── [缺失] /api/market/*   ← ETF 行情全功能（代码完整待注册）
  │
  ├── JWT 认证层 (auth/)
  │     ├── jwt_handler.py         ← HS256 验证 Supabase JWT
  │     └── deps.py                ← FastAPI Depends 注入
  │
  ├── 服务层 (services/)
  │     ├── finance_api_service.py ← ETF 数据（AkShare 源、三级缓存架构）
  │     ├── watchlist_service.py   ← 自选股 CRUD
  │     ├── qa_service.py          ← RAG 问答编排（🩹 有 Bug）
  │     ├── document_service.py    ← 文档处理的完整管线
  │     └── spot_cache_scheduler.py← 缓存定时刷新（🔌 未启动）
  │
  ├── RAG 管线 (rag/)
  │     ├── embedder.py            ← text2vec-base-chinese 中文嵌入
  │     ├── chunker.py             ← 滑动窗口分块
  │     ├── retriever.py           ← 混合检索（向量 + 关键词）+ RRF 融合
  │     └── prompt_builder.py      ← 提示词构建 + 反幻觉护栏
  │
  ├── LangGraph 图 (graphs/)
  │     ├── qa/graph.py            ← 意图分类 + 格式分析
  │     ├── document/graph.py      ← 文档类型 + 结构分析
  │     └── [缺失] lyra/graph.py   ← 未创建
  │
  ├── 传统 Agent (agents/)
  │     ├── question_agent.py      ← 关键词规则引擎（5 种意图 + 榜单 + 行情）
  │     ├── document_agent.py      ← 文档类型规则引擎
  │     └── output_format_agent.py ← 意图 → 格式映射
  │
  ├── 存储层 (storage/)
  │     ├── supabase_client.py     ← Supabase 客户端工厂
  │     ├── chat_repo.py           ← 会话 / 消息 CRUD
  │     ├── document_repo.py       ← 文档分块 CRUD
  │     └── embedding_repo.py      ← 向量检索 + 关键词检索
  │
  └── 外部数据源
        ├── akshare → 全量 ETF 行情、费率、K 线、分时、资金流向
        ├── Supabase → 会话、消息、文档向量、自选股
        └── glm-5.2（通过 Anthropic 兼容层）→ LLM 推理
```
